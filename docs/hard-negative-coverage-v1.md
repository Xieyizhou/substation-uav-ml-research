# 困难负例识别覆盖设计 v1

日期：2026-09-07。状态：设计草案，待资产清点及实际位姿冻结；不是采集完成回执。

本轮只设计覆盖与准入，不启动采集、训练或封存新场景评估。后续独立产物目录建议为 `hard-negative-coverage-v1`；全部产物保持 `training_admitted=false`、`promotable=false`。开发训练使用资格与正式训练准入分开记录。

## 1. 证据与目标

依据 `docs/results/ml_exposure_controlled_diagnosis_20260907.md` 和 `exposure-controlled-diagnosis-v1/visual-review-v2.json`：历史 D 的 67 个误检预测来自 30 张图像、20 个位姿，实际框内内容为建筑 42、地面/阴影 12、混合结构 7、普通柜体 4、杆体 2。它们是跨 seed 的预测数，不是 67 个独立对象，也不是自然场景发生率。

目标是补齐“实际混淆结构 × 尺度/视角 × 边缘/遮挡 × 光照”的覆盖。建筑和地面优先，但不按上述框数机械分配样本。当前 X/Y 与训练预算之间的误检类别会变化，不能只围绕历史 D 的变压器预测收集负例。

这里的内容分类是审核与覆盖元数据，不增加检测类别；确认全图无四类目标的负例仍使用空标签。普通柜体必须由资产身份和视觉审核共同确认，不能仅因不在计划目标列表中就视为负例。

### 冻结前的构图约束

- B1/B2/M1 至少覆盖两个方位和近、远两个投影尺度；C1/C2/P1 至少两个方位。尺度按原图结构 ROI 占比记录，而非只按相机距离推断。
- 对紧凑结构，暂定 ROI 面积占比小于 10%、10%–35%、大于 35% 为小/中/大；细长杆体、地面边缘另记宽高占比，不强套面积分档。这些是设计分档，不是历史验证阈值。
- B2/C2 明确记录接触左、右或下边缘；截断不是单独内容类别。M1 记录各组成对象，无法分清时保留 `unknown`，不按面积猜测唯一对象。
- 两种光照采用既有正常光与低冷光的对应配置，但需在冻结时解析实际数值、来源文件和哈希。每对仅允许光照字段变化；几何、材质、背景、相机和传感器一致。
- 不新增材质因子、不全场统一灰色。若现有资产不能覆盖某项，登记资产缺口，不擅自改动布局或借用封存场景。
- 先清点非目标资产 ID、布局 ID、对象组合和可用候选，再冻结具体位姿。当前表不虚构资产、世界路径或合法性已通过的状态。

## 3. 角色隔离与来源关系

旧 48 张配对开发图、48 张无目标开发图保持评估用途；审核截图和误检裁剪仅作证据，不进入训练。封存新场景继续不访问。

本批全部登记为 `training_candidate_development_only`，不从中随机拆出“独立测试集”。两种光照、裁剪和后续派生归同组。将来若增加评估集，必须在采集前按布局、资产、实例及录制来源确定角色，不能用不同图像哈希证明独立。

必记关系：`layout_id`、`asset_ids`、`scene_instance_ids`、`recording_id`、`pose_id`、`source_group_id`、`pair_id`、`variant`、`parent_ids`。分别报告图像数、位姿组数、布局数、资产数及重复结构数；即使最终 96/96 通过，也只代表 48 个位姿组。

## 4. 识别与审核账本

采用“候选帧 → 内容 ROI → 模型预测”的三层关联，避免把模型预测类别当实际内容。

| 层级 | 必填内容 |
| --- | --- |
| 候选帧 | 唯一 frame_id（含 pose_id 与 variant）、数据角色、全部来源关系；图像/标签/世界/传感器/协议哈希；实际标注模式；计划及实际相机检查；全图四类目标存在状态 |
| 内容 ROI | roi_id、原图坐标、building/ground_shadow/mixed_structure/cabinet/pole/unknown、多标签组成、可见性、遮挡、边缘接触、尺度、证据图哈希、AI 辅助审核理由和时间 |
| 模型预测 | 权重身份、seed、协议、预测 ID、原图框、类别、置信度；关联 ROI 或 unknown；审核性质与理由；跨 seed 的重叠关系 |
| 准入结果 | 决定 pending/pass/reject、缺陷原因、复核证据、图像及标签哈希、重复关系、成对完整性、development_eligible 与正式准入标志 |

ROI 是覆盖证据，不写入四类目标训练标签。新图即使没有模型误检，也必须审核内容 ROI 和全图；模型预测只能提供诊断，不能决定图片是否留用。

审核前固定待查模型列表及权重哈希。建议沿用历史 D、X-300、Y-100 的全部三个 seed，以覆盖不同预算下的误检变化，而非挑表现最差 seed。正式阈值仍为 0.37；若保留 0.001 输出，单独标为诊断，不能与正式误检数混算。此处仅定义后续流程，未执行新推理。

## 5. 质量门禁

1. 计划冻结：实际成员、世界配置、光照数值及来源身份齐全后才能采集。
2. canonical 检查：`full_2d + visual-instance + top-level-equipment` 一致；实例映射可解析无碰撞；计划/实际相机光心及载体参考点处于地图内且不接触扩张 0.25 米的障碍物。保留位姿误差、时间同步和稳定帧约束。
3. 负例确认：世界身份检查与全图逐图审核共同确认四类目标均不可见。目标存在、局部露出或无法确认时不得输出“已通过空标签”。意外出现目标的帧退出本批负例流程，进入待核验；不得删除目标标签或自行改为正样本凑数。
4. 标签/图像一致：空标签须是已核验的真实文件，而不是标签文件缺失。截图、图像、标签哈希与已有审核决定一致；汇总入口不生成自动通过。
5. 成对检查：同位姿两光照全部通过，结构差异符合白名单；任何一张失败则整对暂缓。技术重试最多三次，语义失败先修复原因。重采保留原失败和新尝试身份。
6. 去重：文件哈希、原尺寸像素与来源谱系联合核查。设计变体登记关系不删除；与旧开发/保护成员冲突时排除，保护参考仅作成员/指纹排除，不访问保护标签。

## 6. 试采验收与后续训练边界

试采须覆盖全部八个单元。24 张全部审核、12 对完整且门禁无缺失后，才按冻结清单展开余下 72 张；不以误检率高低决定试采是否成功，不要求每张触发误检。审核显示构图未覆盖预定结构时记为覆盖缺口；修订版本、保留记录后再补缺。

覆盖报告同时列计划、已采、质量通过、完整对、ROI 覆盖和缺口。模型层面按内容单元报告含误检帧比例、每图误检数、预测类别、置信度和 seed 波动；一图可含多个结构，分别报告“包含该结构的帧误检率”和“经逐框确认落在该结构上的误检数”，不混用分母。零样本单元为 unavailable，不记为零误检。

本批经过模型查看，且可能成为训练成员，因此其训练后表现只能称训练成员拟合诊断。效果判断仍使用原冻结开发集；不得用本批误检消失宣称泛化。

下一次训练协议另行冻结。优先检验同预算、同正样本曝光位置下，旧负例池与扩展负例池的替换对照；明确回答负例组成变化的效果，不同时改变总负例配额、训练步数、类别重采样或增强。保留三 seed、旧数值门槛及原始/光照全图与逐类召回双参考下降不超过 5 个百分点的门禁。对本批计数和新实验的共同参考需在实际成员冻结后再确定，不沿用未经核验的临时训练配比。
