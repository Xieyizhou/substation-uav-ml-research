# 电抗器遮挡、截断与远距离条件补充：预检方案

## 依据

当前训练池 72 个电抗器标签的逐图审核显示：64 个 `clear_body`、5 个 `small_clear`、3 个 `partial_occlusion`，没有明确的 `occluded`、`truncated` 或 `occluded_small` 训练状态。开发新增漏检的 8 个电抗器目标中，M04、M11、M16、M21、M06、M24 属于这三类缺口，M08、M22 则是清晰主体仍失败的结构辨识对照。该结论来自本轮具体图像和框，不是按类别曝光次数推断。

## 冻结前的候选矩阵

下一阶段只允许使用新布局或新设备资产，所有候选在采集前登记地图、资产、实例、位姿、录制和派生关系。建议先形成三个条件层，每层 4 个独立位姿（共 12 个位姿），每个位姿保留原始外观和一个中性外观变体；另保留 4 个清晰主体控制位姿。候选规模只是设计上限，不能替代采集后的质量准入。

| 层 | 目标内容 | 必须保留的证据 |
|---|---|---|
| 遮挡 | 前景设备遮住圆柱下部或侧部，主体上部仍可辨 | 前景实例身份、目标剩余主体、遮挡关系 |
| 截断 | 目标接触左／右／下图缘，主体仍有可见部分 | 图缘接触、实际相机位姿、完整真值框 |
| 远距离局部 | 目标短边约 32–64 px，无遮挡或轻遮挡 | 原尺寸框、可辨内容、距离和方位 |
| 清晰控制 | 与上述层相同类别但主体完整无遮挡 | 完整主体和基座，作为结构辨识对照 |

遮挡和截断只改变布局／相机关系，不同时改变材质、光照和标签结构；原始／中性变体共享同一位姿、实例和标签。不得把同一布局的变体计作独立场景。若无法同时保持实例身份唯一、完整标签和相机合法性，该候选不得进入采集。

## 采集前门禁

执行顺序固定为：计划冻结 → 实际模式／实例映射核对 → 相机范围与障碍物扩张检查 → 连续稳定帧与同步核对 → 全图标签核对 → 逐图 AI 辅助审核 → 去重与谱系隔离 → 数据版本冻结。没有实例掩码时，审核只记录可辨内容和遮挡关系，不宣称像素级可见性认证。

每个位姿最多 3 次技术重试；语义冲突、身份不明、目标实际不可见不能靠重试放行。目标仍可见的局部必须保留目标标签，不能直接置空；无法确认的目标进入待定。所有失败候选保留原因并按条件补缺，不按数量凑齐。

## 训练与评估出口（仅下一阶段）

冻结后再设计单变量训练对照：共同可信池保持不变，将新增条件候选按类别实例和谱系受控替换，保留清晰控制；固定 v2.11 初始化、三 seed、现有 CPU／640／阈值协议。先做真实加载器预检，确认完整标签、曝光账本和派生关系，再决定是否训练。评估必须继续使用现有 48 张四条件配对图、48 张无目标开发图，并增加新布局／新资产测试集；不以开发成绩挑选成员或阈值。

本方案尚未采集、训练或修改历史产物。当前所有诊断及未来候选均保持 `training_admitted=false`、`promotable=false`。
