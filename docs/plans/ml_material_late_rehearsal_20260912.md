# 待训练配置：固定曝光多重集的来源级后段材质复习

## 目标与边界

检验重新分配材质成员出现时点是否改善学习保留。当前仅冻结配置并预检，不启动训练、不补采、不改标签、不调阈值、不解封新场景。所有产物training_admitted=false、promotable=false。不设置定时任务。

历史T-7/17/27为直接对照；新配置L-7/17/27，均从v2.11独立初始化，不从T终点继续训练。CPU640，batch/nbs6，AdamW，恒定LR0.0005，无预热，450优化步2700次曝光，仅原位置的冻结亮度增强；其他配置保持T原值。仅使用终点last.pt，不挑seed或checkpoint。

## 调整规则

仅重排原30个材质槽位上的成员，包含原暖色、冷色、目标主体灰色。每成员次数、完整类别实例曝光、负例及其他2670个位置不变。统一覆盖全部12个登记来源，不按本轮错误挑成员。

第一目标：最大化最早的来源末次曝光槽位。最后12个材质槽位各由一个不同来源占用，达到鸽巢原理给出的槽位上界。该目标针对图像槽位；同一优化步内两个槽位不增加时间间隔。

第二目标：在上述约束下最小化成员替换槽位数，使用精确子集动态规划；按版本、seed、槽位及成员ID的SHA256固定消除等价解。早段优先保留原成员，剩余缺额按固定哈希填入。小规模穷举验证最优计数，不改训练环境安装额外求解库。

三个seed均只改变12个位置。所有来源的末次曝光分别不早于第206、271、283步。不能称为“全部来源在最后150步复习”：原第300步后的槽位只有6、9、9个，12来源无法全部覆盖。不能为达到更漂亮的覆盖描述扩张预算。

## 对照解释

总成员多重集和颜色曝光次数不变，但部分batch组成、窗口类别分布及成员与亮度系数组合发生变化。比较回答来源级时点安排策略的整体效果，不是纯增加复习次数或纯颜色因素的因果效应。区别于历史完整batch交错：此次保留所有非材质位置，仅改变30个材质槽位中的12个。

## 数据与真实预检

复用T完整且哈希有效的成员及全标签审核；保留历史内容风险边界，不把同源图视为独立场景。每个新配置真正加载2700次、450批，核对成员顺序、完整标签、亮度系数及增强后图像张量；未改变的曝光记录和batch必须与历史T一致。预检禁止优化器、反向传播和训练验证。已有按batch记录的监督与图像哈希由训练入口逐步消费。

预检及针对性回归通过、v2.11固定40文件核验通过后签发ready_for_training_not_started。默认训练入口仅核验；未来必须显式传入--train。每单元最多3次技术尝试，失败独立留痕，语义错误停止，取消后清理子进程。
