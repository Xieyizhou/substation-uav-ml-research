# 下一轮：材质学习轨迹复现诊断

## 目的与选择理由

继续推进到三个seed的训练，但不盲目追加材质比例。历史已做完整批次交错对照；当前T的灰色曝光本来分散于450步。因此先复现T原轨迹，区别已曝光目标始终未学稳、曾命中随后丢失，以及原有能力何时发生损失。

这是一轮诊断性复现训练，不是新的优化成果。T按事先约定的颜色保留问题选择，不能按seed成绩挑选。复用T-7/17/27全部成员、2700次曝光、批次及顺序、冻结亮度、初始化、CPU640、batch/nbs6、AdamW、LR0.0005、450步；无新图、标签修改、阈值修改或新场景解封。所有产物training_admitted=false、promotable=false。

## 执行顺序

1. 核验历史T终点、真实曝光、七条件推理和全标签审核。保留实际曝光成员的全部真值及得益/损失，不只看计划目标或灰色错误。无法确认内容不认证为高质量。
2. 独立实现观测保存：初始、每50步，以及每次暖/冷/灰材质曝光批次的前后状态。时点由序列预定，不由成绩决定。保存raw与EMA状态及身份；保存操作不得改变RNG、模型、EMA或优化过程。训练中不执行诊断推理。
3. 默认只预检。复用并重新核验真实加载器回执，检查新观测工具无状态副作用、450步不变、文件哈希有效及进程清理。通过后显式连续启动三个seed，每单元最多3次技术尝试；语义冲突停止。
4. 训练结束检查终点EMA与历史T逐张量一致性。若不一致，先调查观测副作用/环境或数值变化，不把轨迹解释为历史T的真实中间状态，不按成绩决定是否接受复现。
5. 对冻结的同源七条件84张图，在各时点离线执行正式0.37和诊断0.001推理，参数保持NMS0.7、max_det300、同类一对一匹配IoU0.5；完整标签保留。raw/EMA分别标记。固定开发96图仅在0、150、300、450等预定时点补诊断，终点仍是唯一候选评价权重。

## 解释约束与出口

命中随后丢失支持能力不稳定/干扰假设；从未命中仅表示所观察时点未命中，不能证明网络从未学会，也不能直接归因于步数不足。原图与增强后的实际张量不同，原图拟合成绩不代表所有增强训练输入上的拟合。

同源图、重复seed和检查点不增加独立场景数。完整门禁沿用已冻结协议。本轮不选最优中间checkpoint，不增曝、不自动调整模型结构。诊断结束再决定一个优化因素；目标是让下一次优化依据学习过程证据，而不是继续猜测颜色是唯一原因。
