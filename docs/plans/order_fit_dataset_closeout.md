# 本轮训练集收尾验收清单

目标仍为可用、可追溯的有界开发训练集，不是完成更多审核工具。完成后依照已授权的配置接入训练。不得以缩小到容易通过的成员集合代替全池处理。

## 固定剩余验收项

1. 对全部 429 个成员给出最终去向：质量支持、具名暂缓或已隔离。继承明确的逐图质量决定；诊断性审核或仅有哈希关联不算质量批准。不得按拟合成绩选图。
2. 核对拟使用成员的来源、完整标签、角色和登记派生关系；披露共享布局、资产及成员级身份局限。保留已核验的精确指纹排除结果，但不称其为独立场景认证。
3. 完整图像与完整标签导出到独立目录；暂缓整图不导出，历史文件不改。保存所有未收录成员的理由、类别和来源覆盖损失；不足以支持下一轮实验时报告不足，不以小集合冒充目标完成。
4. 真实数据集和加载器逐成员遍历，核验图像尺寸、标签、顺序与张量；不训练的预检阶段禁止优化器和反向传播。
5. 相关回归、v2.11 固定 40 文件、输入输出哈希、恢复行为核验；交付一份统一中文报告及完成回执。
6. 数据集完成后冻结训练序列及预算。沿用已锁定的配置、seed 和 CPU 方案；变更成员后的精确曝光不可直接借用旧序列。训练前重新验证有效预检回执。

## 不再扩展的事项

- 不继续追查与新数据集成员、监督质量、来源隔离和直接对照无关的历史实验。
- 历史临时 SciPy 环境缺失保留为复算限制；若新步骤确实依赖旧求解最优性，则单独验证该要求，而非重建整个历史。
- 不重新签署旧文件，不自动生成审核通过，不降低阈值，不解封新场景。

后续使用统一成员去向清单推进；只在证据引出具体必要缺陷时增加针对性检查。普通阶段完成不再要求用户说“下一步”。
