## 剩余门禁与下一优先动作

1. 逐成员收口全图覆盖及来源角色证据；现有文件／原尺寸像素排除无碰撞，不等于位姿或资产独立。历史世界映射事后追溯不改称原采集已通过新门禁；未解决项继续具名暂缓。
2. 在最终成员上核验旧预算能否满足完整类别实例曝光及风险限制，明确常规子集同源集中度；不能为启动训练而放宽约束或恢复暂缓成员。
3. 可行才冻结三 seed 曝光与亮度数组，并通过真实全序列预检后自动训练。候选单遍加载成功不能替代此检查。

这是一个明确的数据组成判断，不是模型效果结论。本轮没有训练，也未重复任何已经完成的模型推理。
