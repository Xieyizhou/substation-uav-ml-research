# 小尺度补充样本：同曝光、同批次、不同顺序对照

## 已证实的现象

SR1100 与 SM1100 六个训练终点及固定开发评估已校验。材质全图召回三 seed 均值分别为17.78%和43.89%；灰色替换有方向性收益，但无目标帧误检率分别为66.67%和54.17%，均未通过既定门禁，不能形成可晋升模型。

本轮37张唯一图像的210个正式阈值误检框均已查看全图和各自裁剪，独立AI辅助观察记录包括159个柜状块体、29个灰色大块体立面、15个多结构重叠、7个地面／阴影。数字是预测事件数，不是独立结构或场景数。视觉柜状外形不等于目标开关柜身份；不能把画面的计划对象ID赋给所有预测框。

来源核对确认上述37张图对应19个位姿，复用正常与冷光条件。原保存世界的蓝色柜状块体资产为cabinet_center（非目标cabinet），灰色大块体为control_building；四类目标模型在这些负例世界中已移除。计划文件及其世界、配置等文件哈希已重新核验。此核对不能替代逐像素实例掩码认证；混合结构不自动分配唯一资产ID。

六个单元实际曝光均为6600次。前6000次包含全部972次无目标图曝光；末600次均来自新正样本。SR末段8张、SM末段16张，均只覆盖4个配对位姿来源。末段完整标签实例曝光为开关柜1200、变压器750、电容器组300、电抗器150。计划类别均衡不等于全图监督均衡。

这支持优先测试末段集中曝光的影响，尚不能证实遗忘机制，更不能将所有误检归因于材质。原始外观补充组同样误检激增，因此下一轮不单独归罪于灰色材质。

## 冻结的实验

独立目录：`small-scale-material-control-v1/interleaved-tail-control-v1`。

新增 ISR1100、ISM1100 两个家族，各 seed 7、17、27，共六个独立训练单元，分别与同seed已完成SR1100、SM1100比较。历史ICG1000只作较短训练预算的背景参考。

保持各历史单元完整的1100个batch及批内六张图顺序。前1000个历史batch和末100个新增batch各自的内部顺序不变：累计比例分配将新增batch放在新序列第11、22……1100步，其他位置依次填入历史batch。不拆分、不重新抽样、不按结果调整。

每个成员、完整类别实例、谱系、子集及批次总曝光完全不变。亮度系数随原batch成员一同移动；成员与亮度组合不变。负例总曝光仍为972次，但负例位置会随批次移动——这是顺序干预的一部分，不是旧位置保留实验。

每50步报告图像、类别实例、谱系和子集账本。小来源池和末段类别曝光不均衡不在本轮修复，只作为控制条件保留。因此结果只回答“这些相同批次改变时间顺序”的效果，不回答增加负例总量或新增来源的效果。

## 训练与门禁

均从v2.11独立初始化，CPU、640、batch/nbs=6、AdamW、LR=0.0005且恒定、无预热，仅原冻结亮度增强，1100优化步，终点last.pt。两个4线程worker并行，同seed两家族成对，三个seed顺序运行。不得按某seed成绩提前停止或替换seed。

六个真实加载器逐一遍历全部39600次曝光。各新batch图像张量、完整cls/bboxes/batch_idx张量必须与其历史实际batch逐一完全一致；亮度像素日志除了位置编号之外也须完全一致。预检禁止优化器、反向传播和训练验证。训练过程中再次逐batch核验预检张量。

历史审核、原图、完整标签、权重、实际曝光和配置身份失效时阻断；技术失败单独留痕，单元最多三次尝试，不拼接不完整权重。默认入口不训练，显式训练入口必须消费有效就绪回执。取消及异常清理本次子进程。

训练全部成功后自动执行固定开发推理：48张配对图及48张无目标图；CPU640，confidence0.37和0.001，类别相关NMS IoU0.7、max_det300，同类一对一匹配IoU≥0.5。推理结果不自动产生视觉审核通过决定。

原始计划命中均值≥5/6、最差seed≥0.75；材质均值≥0.5、最差seed≥1/3；背景／光照均值≥0.6；无目标FPR均值≤0.1、最差seed≤0.2。原始／光照全图及逐类召回均值相对冻结retained_reference-450和历史A不得下降超过0.05。直接顺序对照不是能力保留参考的替代。

所有产物training_admitted=false、promotable=false。不采集、不改标签、不解封新场景、不改阈值。通过仅为开发候选，未通过同样是完整结果，不自动追加新配比。
