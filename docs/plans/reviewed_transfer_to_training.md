# 从条件迁移核对推进到训练启动

目标：在用户授权下连续推进诊断、冻结、真实预检与启动，不因普通阶段完成反复请求继续。不能为了启动训练而绕过质量门禁。历史风险图保持暂缓；不改历史标签、不改变评估阈值、不解封新场景。

1. 复用已完成的十图拟合核对；限定四个具备登记同源关系的锚点，检查其现有 56 个变体。使用当前全部六份权重和双阈值协议，逐模型区分实际已曝光与零曝光。相同框不认证几何、位姿或可见性完全相同。
2. 根据此有界诊断确定下一训练因素。若已有曝光变体仍错误，优先定位该条件的采样或拟合问题；若同源变体也稳定，优先检查尺度／视角／上下文变化。不得把同源外观变体说成视角对照，不再扩大到全池重复审核。
3. 冻结一个有证据支持的对照。保持当前初始化、预算、学习率、三个 seed、CPU 加速和开发评估；只允许选定实验因素变化。若需新采集、标签修订或无法隔离实验因素，报告具体缺口及所需范围，不自行扩大采集。
4. 新序列或增强必须进行完整标签变换与实际加载测试，固定曝光、亮度及新增参数数组；默认入口只预检。三个 seed 的真实全序列预检及相关回归、固定模型文件完整性通过后，按已获授权自动启动训练。
5. 以进程日志中的实际训练批次和损失记录确认启动，不能仅以创建进程为完成。新产物始终 training_admitted=false、promotable=false。

本文件先冻结推进边界，具体训练因素等待步骤 1–2 的证据，不预先宣称尺度或背景已被确定为根因。
