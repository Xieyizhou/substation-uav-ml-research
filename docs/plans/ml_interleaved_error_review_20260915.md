# 交错曝光实验：错误审核结论

本轮六个训练单元、正式与低阈值开发评估均已完成。新增 AI 辅助视觉审核已完成，但两个家族均未通过固定模型门禁；不选择候选，不晋升。所有新产物 training_admitted=false、promotable=false。

## 审核范围与证据

逐图查看无目标集全部29个误检框，来自12张唯一图像；查看相对同seed原分块顺序对照，原始/光照条件全部64次新增漏检，对应14张图中的35个唯一图像—真值目标。每个目标使用自己的全图叠框和裁剪，不以计划目标裁剪代替非计划设备。审核决定、时间、理由、图像/标签来源、预测和证据页哈希保存在实验目录 evaluation/error-review-v1/review.json；漏检证据在 evaluation/loss-review-v1/evidence.json。

四条件全部转移另保留1440条模型—目标记录：持续命中716、持续漏检430、得益152、损失142。不是1440个独立样本，也不表示这些记录全部经过人工性质的视觉审核。开发数据仍只有12个位姿组；seed重复不增加独立性。

## 已证实的观察

误检覆盖内容：灰色立面19框、立面与杆等混合结构6框、蓝色柜状物4框。不是仅凭整帧主题认定结构；例如F04中一个框混入杆下段、基座、地面和长阴影，不能简单归为地面。视觉外形不认证仿真资产身份。

35个新增损失目标：遮挡12、图缘截断11、内容有限7、主体清楚5。主体清楚的目标中包括电抗器L10、L17、L21，也包括背面朝相机的柜体L25、L30。可见主体完整不等于类别细节充分，但清楚电抗器的退化说明不能把所有损失归咎于遮挡或标签内容不足。

64次事件的固定低阈值诊断：同类低置信度51、错类5、同类定位不足5、未发现合格保留预测3。此为机器匹配分类，不宣称逐一视觉审核全部低阈值框；受NMS与max_det限制，最后一类不等于网络未产生候选。计划命中与全图分配冲突为0。

没有实例掩码认证。本轮图缘观察不改写历史截断标记，也不据此删除真值或放宽门禁；多柜重叠区域的像素归属仍未认证。

## 判断与唯一优先建议

支持的结论：在此次固定成员曝光、批次组成与成员—亮度组合的顺序对照中，交错曝光显著缓解无目标误检，但出现材质/光照与类别能力取舍；它不是完整解决方案。不能据此认定只依赖颜色、确认唯一遗忘机制或宣称跨场景泛化。

下一优先方向是**已有权重的逐结构训练拟合核对**，暂不再训练：固定本次清楚电抗器和灰立面/杆混合误检结构，核对实际已曝光训练成员的完整标签、最新审核与来源，比较分块/交错同seed在这些训练成员及对应开发条件的正式和低阈值表现。训练侧仍错支持未学稳；训练侧正确而开发侧错支持条件迁移受限；身份或标签风险先独立处理。该核对之后才决定采样/优化对照或来源多样性补充，不临时调阈值、挑seed或继续堆训练步数。

## 核验边界

本次新增与相关21项回归通过，覆盖缺失/重复/未知审核、过期证据、身份而非数组下标匹配和曝光顺序约束。v2.11固定40文件重新核验通过；不是全仓测试通过，也不表示基准数据所有图像/标签字节重新审核。没有新训练、补采、历史标签修改或封存场景访问。
