# 已审核增曝白名单与谱系上限训练对照

本轮在独立目录 `lineage-capped-exposure-control-v1` 中执行三个 seed（7、17、27）的开发训练对照。历史 reference-450 与 hold-450 只复用，不重写。

## 数据政策

已逐框审核的 49 张图中，31 张未记录内容不足，构成本轮允许增曝的白名单；其余正样本即使尚未被判为风险，也不得增加曝光。已知风险 30 个成员的 28 个登记谱系另设联合曝光上限。成员上限与谱系联合上限均以同 seed 的原始 reference-450 为基准。占位成员谱系不证明独立场景，此处仅对已登记关系负责。

因此，同源尚未审核变体也不能被求解器用来转移增曝。没有自动给未知成员或同谱系成员下可见性结论；只是保守限制其曝光。仍保留部分历史风险的原有曝光，不宣称数据池无风险或正式训练准入。

## 冻结比较

维持 2700 次图像曝光、450 步、batch/nbs 6；基础 972、常规 702、桥接正例 540、负例 486。原定四张暂缓图为零，其余正样本至少一次。四类完整标签实例曝光与 reference 精确相等，负例位置与成员不变。求解目标先最小化单图最大新增曝光，再在该最优值下最小化计数绝对变化。本次最优最大新增曝光为 12，这不是质量阈值。

序列按版本化 SHA-256 从过量成员位置选取空位，在同子集内轮转填充增量成员，其余位置保留，冻结每 50 步完整曝光账本。比较的是整体受限补偿政策，不是纯类别总量因果实验。

## 训练与评估

真实数据集/加载器三个配置各核验 2700 次实际抽样和完整标签，禁止优化器与反向传播；预检通过才启动训练。v2.11 独立初始化，CPU、640、AdamW、恒定 0.001、无预热、增强关闭、450 步，保留全部 seed 的终点 last.pt，不按成绩挑选。

正式推理 confidence 0.37、诊断 0.001，NMS IoU 0.7、max_det 300、同类一对一匹配 IoU≥0.5；固定已查看开发图 48 对照图与 48 无目标图。沿用既定数值和能力保留门禁，不解封新场景。逐框审核本轮无目标误检及原始/光照电抗器、电容器组新增漏检。

所有产物 `training_admitted=false`、`promotable=false`。不修改标签，不采集训练图，不建立定时/跨轮任务。失败尝试独立保存、清理进程、最多三次技术尝试；首次入口绑定错误发生于优化器创建前，使用新版本入口修复并重新验证，不覆盖失败记录。
