# 地图与 PX4 本地坐标配准

地图原点是 Gazebo 世界 (-10,-10)，而最近悬停试飞出生点为 (-8.5,-8.5)。因此在轴向一致、忽略估计偏差时，PX4 本地原点在地图中为 east=1.5、north=1.5。旧转换把两者原点当成同一点。

共用转换实现：`src/planner/local_frame.py`。地图配置可添加：

```json
"local_frame": {
  "east_offset_m": 1.5,
  "north_offset_m": 1.5,
  "rotation_deg": 0.0
}
```

这是该出生点的**名义配准示例，不是实测飞行准入配置**。偏移表示 PX4 本地原点在地图中的位置；旋转表示局部 east/north 平面到地图 east/north 平面的逆时针旋转，绝不是机头 yaw。地图到本地使用逆变换。

已接入标准 A* 航点、航线预览、重规划起点/输出及 LiDAR 落点栅格。雷达返回的 obstacle_east/north 仍保留 PX4 本地坐标，grid_x/y 则明确属于地图。返航复制已转换航点，不再次转换。

未配置 local_frame 的历史工具保留 identity 行为，日志标为未校准，不能把兼容性视为实测对齐。显式配准配置目前拒绝旧 map_baseline 感知和 active_semantic_inspection 入口，避免它们静默使用未转换坐标。

本次只统一水平坐标。垂直 down 仍使用现有本地高度约定；起飞高度、地图绝对高度、雷达安装外参及 EKF 原点/航向重置仍需独立核验。没有把名义 1.5 米常数写进历史地图或默认配置。

下一门禁：在实际 Gazebo/PX4 会话中用同步位姿测得原点、旋转和安装外参，验证已知墙体与多个航点的双向映射及原点重置保护。通过前不开展横向自主飞行，不宣称实际避障认证。
