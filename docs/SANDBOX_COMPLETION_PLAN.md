# 沙盒三个目标的完成条件

本文件记录持续任务的完整范围。局部测试通过或源码变小不代表任务完成。

## 1. 稳定核心与可靠验收

- 修复现有测试失败并解释原因，不跳过失败、不修改历史证据使其通过。
- 核心测试不依赖本机历史研究数据；研究复现独立声明依赖、数据和执行环境。
- 干净源码导出可以运行核心验收；CI 使用同一入口。
- 桌面显示当前可执行能力、阻塞原因、任务状态和恢复办法。

## 2. 桌面中的模型迭代闭环

- 沿用现有场景，不扩展地图。
- 在界面完成采集、查看和纠正样本、审核、注册数据集。
- 未审核预测不得进入训练真值；记录审核来源，并按采集来源隔离数据划分。
- 从历史模型微调，比较结果，选择已验证模型执行任务。
- 实际浏览器操作验收整个流程，包括真实训练和所选模型的任务执行；单元模拟不替代此验收。

## 3. 历史证据独立于当前源码路径

- 证据包保存冻结源码、配置、模型与产物身份，保留原回执字节。
- 搬迁后仍可独立验证，拒绝缺失、篡改和路径逃逸。
- 当前核心可以演进；不能静默将旧验证结果解释为新实现已经验证。
- 将实际运行入口接入新协议，不能仅交付一个无人使用的打包工具。
