UAV Research Sandbox — macOS Developer Preview

1. Drag UAV Research Sandbox.app to the Applications shortcut.
2. Open the App and start Demo Profile immediately; no repository is required.
3. Clone the project and create its Python environment only for Development or Formal.
4. Install PX4 and Gazebo only if you want to run simulator workflows.
5. Use Get started to verify Development prerequisites before a flight.

This preview is ad-hoc signed and is not a standalone simulator installer.
It includes the self-contained Demo but no datasets, model weights, research
outputs, PX4, Gazebo, or Python runtime. For build and troubleshooting, see:
https://github.com/Xieyizhou/substation-uav-ml-research/blob/main/docs/MACOS_APP.md
