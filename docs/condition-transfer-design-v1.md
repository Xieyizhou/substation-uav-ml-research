## 单一优先假设

**训练中的可辨识面板—主体低对比条件和来源支持有限，可能限制条件迁移；需要用真实材质改变进行受控验证。** 当前只有覆盖集中与开发错误证据，不足以把低对比认定为唯一根因。尤其光照开关柜漏检以低置信度和定位不足为主，不全是错类，单纯改变色相不一定有效。

先核对面板条件，再做“保持主体、只改变面板相对主体材质参数”的小规模同位姿重放验证；不要直接在二维真值框内涂色、降低局部对比，也不要未经实例证明用前景遮挡物替代目标。

## 推进顺序与停止条件

### 1. 补齐条件证据

审核队列冻结当前全部 43 个电容器条件缺口、1 个开关柜未知项，以及 5 个已链接低对比开关柜事件的重放适用性复核。逐框查看原图、完整标签、局部及来源；分别记录主体/面板/基座、可见面、遮挡、截断、颜色和对比关系。

开发队列保留两类在四条件下全部 148 个帧内真值事件及三个 seed 状态，优先材质持续漏检、光照开关柜持续漏检；同时保留持续命中、种子间变化，不只看损失。当前开发误检记录只作负结构核对线索，不进入训练。正负外形相似不等于资产身份相同。

所有新增判断为 AI 辅助审核，绑定时间、理由、原图/标签/证据哈希。历史条件观察不是质量批准，未能解析实例或组件时保持 unknown。不得把电容器“没有面板”强行编码成低对比面板。

### 2. 小规模重放能力验证

只从当前实际曝光且完成全图标签审核、来源唯一、组件归属清楚的训练成员中选取先导图。计划上限为开关柜、电容器各两张；若某类没有可干预的面板，不为凑数替代组件，记录设计不适用。精确成员 ID 要在审核后、任何渲染及模型评分前冻结，按成员 ID 确定性选择，不按模型成绩挑图。

从保存的世界和实际相机位姿生成独立诊断副本。先生成不修改材质的控制重放，要求 RGB 与原训练图逐像素一致；否则先解决重放对齐，不能用漂移后的渲染做单因素认证。

唯一预定干预为：对能唯一归属的面板 ambient/diffuse RGB 使用 `new_panel = 0.5 * old_panel + 0.5 * body`，alpha 保持原值。0.5 是预先指定的材质参数插值系数，不表示实际像素对比度精确减半；不是参数搜索。已同色、没有面板、纹理/PBR 控制无法等价解析时记为无有效干预或不适用，不任意改 shader、主体颜色或其他组件。

保留主体、几何、基座、附属结构、布局、设备实例、背景、地面、光照和传感器。对应材质字段以外的世界差异拒绝。该先导只验证组件解析、改变范围和内容风险，不用候选模型筛选强度或图像。

沿用 full_2d / visual-instance / top-level-equipment、唯一实例映射、全图标签、相机边界与扩张障碍物 0.25m 门禁；位置误差≤0.05m、姿态≤1°、同步≤33.334ms、连续3帧稳定、最多3次技术尝试，取消/失败清理本次进程。0.25m 不是无人机安全认证。

材质变体本就不应与控制 RGB 相同，不能用它认证原帧像素掩码；相机控制重放的像素一致性和材质变体的结构不变性是两项不同检查。全图实例映射及标签必须对应，框差异超过1原图像素进入调查；即使小于等于1像素，也不能擅自覆盖历史标签或宣称数值完全一致。

### 3. 条件成立后才冻结训练对照

先导全部通过后另行发布精确训练协议。目前不签发 ready_for_training_not_started。

- 参考：当前已完成的 0.0005 亮度组，三个 seed，仅在输入/配置/曝光/环境兼容性核验通过时复用。
- 新组：相同 seed 7/17/27、v2.11 初始化、450步、CPU、640、batch/nbs6、AdamW、恒定0.0005、无预热、终点last.pt；保留每次亮度增益。
- 唯一新增因素：审核通过的同位姿面板材质派生条件。不能同时修改光照、颜色增强、类别采样、模型结构或步数。
- 冻结可干预成员后，每个成员按版本/seed/成员/曝光位置的 SHA-256 排序，预定替换其一半曝光（向下取整）。未选位置保持原始图；不得因结果再改比例。四类完整标签实例曝光、每个源成员及谱系总曝光、批次位置和负例成员/位置均不变。派生变体与源图计为同一角色/谱系，不算新增独立样本。
- 风险、未解析和原定暂缓成员不因派生获得放行，不增加其源成员总曝光。完整数值标签不能保持一致时，必须先解释并修正独立导出工具，再判断是否还符合单变量设计，不静默复用旧标签。
- 仅选择已审核正例进行派生是一个明确限定的干预策略，不能解释成所有类别、负结构或全图低对比条件的普遍效果。若先导暴露可辨识性或正负资产歧义，停止训练路径，先形成数据处理方案。
