## 1. 目标与边界

先弄清风险标签应当保留、仅补充元数据、继续待定，还是进入后续独立数据修订设计；不把“内容不足”直接认定为错标，也不把训练命中当作标签正确性的证据。

本方案的实施终点是**有证据支持的修订提案及影响清单**，不是修订训练池或通过验收的模型。

- 建议未来实施使用独立目录 `supervision-risk-revision-v1`；不写入已完成诊断的哈希绑定目录。
- 不改历史图像、标签、审核、权重或评估结果，不导出新训练池，不训练、不调阈值、不补采训练图、不解封新场景。
- 仅在后述门禁通过时允许诊断重放；输出只作证据，不能混入训练或开发数据。
- 不使用跨轮任务跟踪或定时任务。新产物均为 `training_admitted=false`、`promotable=false`。
- 当前只制定方案；本文件没有授权或启动任何重放、修订或训练。

## 3. 流程及停止门禁

### A. 冻结证据与标签语义

绑定上一阶段完成回执、协议、来源清单、逐图决定、对应原图与完整标签、实际曝光账本的身份和哈希。历史模型结果只用于后续影响说明，不参与判断标签去留。

先确认 `full_2d` 在对应采集版本中的框定义、截断字段生成逻辑及实例标签作用域：

- 原始字段 `not_truncated` 究竟是经过检测的结论、默认值，还是导出占位值？
- 框是否按当时的可见极值定义生成？不可用另一套框语义追认它错误。
- 运行标签只能在对应世界和采集上下文内解析，不跨世界按同一个数字认定同一实例。

新增字段分开保存 `historical_truncation_status`、`observed_image_boundary_contact`、`truncation_evidence_status`。触边或视觉争议不能直接覆盖历史字段，也不能只凭框坐标贴边认证真实截断。

输入缺失、哈希过期、来源匹配不唯一或完整标签冲突时，停止对应单元的后续认证，记录具名缺口。其他独立单元可以继续。

### B. 原图与来源核验

每个框核对原尺寸 RGB、完整标签、原始采集回执、世界、相机实际位姿、传感器和实例映射。无损格式转换可接受，但尺寸和每个 RGB 像素必须相同。

- 有回执映射：检查运行标签到设备 ID 唯一，类别和世界一致。
- 缺回执映射：可读取对应保存世界和采集代码寻找证据，但必须把后验重建与原始回执认证分开；不能给历史采集补发新版通过状态。
- T08 若只能核对本图标签行和运行标签，保留该局部身份；不得据此推断跨图实例或独立场景。
- 用完整标签比对区分“坐标正确但内容不足”和“来源/坐标真正冲突”。不能用模型框替代真值框。

### C. 先做两个诊断单元，再决定是否重放其余框

先处理 T30 和 T08：一个代表极窄边缘，一个代表旧来源身份缺口。优先复用已有且哈希有效的重放证据，不因文件名相似直接复用。

若需要新增诊断重放，先证明实例分割入口可靠。仅允许从保存世界生成诊断副本，增加与 RGB 同光心、同视场、同分辨率的诊断传感器，保留设备、材质、光照、几何和原传感器。固定保存的实际位姿，不调位姿追求通过。

门禁沿用：位置误差≤0.05米、姿态误差≤1°、同步差≤33.334毫秒、连续3帧稳定；每帧最多3次技术尝试，语义冲突不靠重试放行，失败/取消/超时清理本次启动进程。

- 实例 ID 必须唯一解析，类别掩码、深度吻合、几何投影不能替代实例掩码。
- 原始与重放 RGB 像素完全一致，才允许掩码作为原帧像素证据。
- 不完全一致时保存差异及框坐标变化，仅作辅助证据；框差超过1像素进入对齐调查，不修改原图或世界来消除差异。
- 组件无法可靠分离时，主体/面板/基座归属保持 `unknown`；可见像素存在不等于类别内容可辨识。

两个试点中可复用的路径通过后，再处理其余需要补证的框。若实例能力或对齐无法建立，停止该认证路径，保留“待定”；不把近似证据升级成标签修订依据，也不为凑齐结果无限重放。

### D. 独立逐框决定

审核时先隐藏模型命中、置信度及 seed，只查看全图、目标局部、完整标签和通过门禁的来源证据，减少按模型成绩挑数据的倾向。所有决定标记为 AI 辅助审核，绑定时间、理由和输入/证据哈希。

每框只能形成以下提案之一：

| 提案 | 所需证据 | 本阶段允许的输出 |
|---|---|---|
| 保留现状 | 来源与标签一致，内容可辨；没有确认的修订理由 | 保留理由，不新增准入资格 |
| 仅元数据勘误 | 框语义和坐标无冲突，明确了字段默认/描述偏差 | 新增旁路勘误提案，不重写原字段 |
| 监督内容不足，建议暂缓整图 | 目标身份可信，但内容不足以支持拟定监督用途 | 整图及同源关系的暂缓建议，不删除原标签 |
| 标签/身份修订候选 | 来源、类别或坐标确有可复核冲突，且修订目标可确定 | 原值、建议值、依据、受影响全图标签的差异提案 |
| 证据不足，保持待定 | 身份、组件或对齐不足以决定 | 具名缺口及下一项需要的证据 |

**禁止只删掉难辨识目标框、却继续把该图作为完整标注训练图使用。** 这可能把仍存在的目标变成未标注负监督。若未来考虑 ignore 区域，必须另行验证数据集、损失和评估对 ignore 的支持；本方案不引入它。

对于整图暂缓建议，列出关联派生组；无法证明可安全拆分的同源变体按组待定。不得只留下模型表现较好的变体。

### E. 只计算修订影响，不制作数据集

基于冻结的现有成员和实际采样顺序，做只读影响核算：

- 分别统计元数据勘误、单框争议、整图暂缓及保守同源组暂缓的影响，不把它们混成一种操作。
- 列出唯一图、登记谱系、四类完整标签数量变化；包含被连带移出的清晰非计划目标。
- 对现有各 seed/家族记录受影响图像曝光、类别实例曝光和每50步窗口的分布。先展示原始剩余曝光，不能悄悄补样或重新分配预算。
- 对比其余31个训练电抗器框作为已有审核参照，避免仅展示待删框或模型损失。
- 开发集维持原角色和现有身份。开发图的争议只能另行登记，不能更改评估分母来改善成绩。

这些只是数据组成和曝光的影响，不是重训练结果，也不能预言模型一定改善。
