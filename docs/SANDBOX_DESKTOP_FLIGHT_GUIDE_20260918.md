# 最新本地电脑端 Sandbox 使用说明（2026-09-18）

## App 与依赖

构建产物：`dist/UAV Research Sandbox.app`。这是本机开发版本，使用所选仓库的最新后端与页面；不是内置 PX4、模型和数据的独立安装包，也不是正式发布或真机飞行认证。

1. 打开 App，选择 `Development`（不要选择 Demo 或 Formal）。
2. 选择项目 `<project-root>`。
3. 执行 `Check runtime`，确认 Python、PX4、Gazebo 等依赖。已有正确配置可复用；不要为消除提示随意升级依赖。
4. 点击 `Start Sandbox`，进入 `Workbench` → `Flight Console`。
5. 若本地服务已经启动，复用该服务，不要同时启动第二个飞行任务。当前浏览器入口为 `http://127.0.0.1:8876/#fly/run`。

## “有 PX4 界面”与“无 PX4 界面”的准确含义

两种模式都运行 PX4 SITL 和 Gazebo 仿真。区别是是否打开 Gazebo 3D 窗口；PX4 本身是飞控进程，不是这里的 3D 界面。本入口不自动启动 QGroundControl。

| 模式 | PX4 / 仿真服务 | Gazebo 3D 窗口 | Sandbox 状态与日志 |
| --- | --- | --- | --- |
| Visual Preview | 运行 | 打开 | 可查看 |
| Headless | 运行 | 不打开 | 可查看 |

## 普通场景飞行：有窗口

1. 在 `Flight Console` 向下找到 `Simulator setup`。
2. 在 `Scenario` 选择已有可用开发场景。
3. 将该区域的 `Display mode` 设为 `Visual Preview`。
4. 点击下方 `Flight smoke` 卡片中的 `Run flight smoke`，核对确认框后启动。
5. 等待 Gazebo 窗口和 PX4 初始化。通过检查后，任务执行起飞、路线与降落；不要同时手工启动另一份 PX4 或用其他地面站接管。
6. 在任务与日志中确认任务结束、降落和进程清理。需要提前终止时使用 Sandbox 的任务停止按钮，不要把关闭 3D 窗口当作安全降落。

这是普通场景飞行入口，不等同于下述新增实时避障验收流程。当前交付未重新执行有窗口模式的完整飞行验收。

## 普通场景飞行：无窗口

步骤与上面相同，但 `Display mode` 选择 `Headless`。没有 Gazebo 窗口是预期行为；从 Sandbox 的任务状态和日志观察进度。不要因为没有窗口而重复点击启动。

## 自定义地图飞行

先在 `Map Studio` 选择通过校验的地图修订和任务，再进入 `Flight Console` 的 `CUSTOM MAP RUN` 卡片。在该卡片自己的 `Display mode` 中选 `Visual Preview` 或 `Headless`，点击 `Run selected map`。

此处的模式选择与下方 `Simulator setup` 是两个独立控件。未选有效地图时按钮禁用是正常门禁。仅飞行请勿选 `Fly and record PNG`。

## 最新接入的实时避障闭环（当前仅 Headless）

在页面顶部 `实时避障仿真` 卡片点击 `运行一次实时避障仿真`，确认后自动执行固定开发场景：起飞 → 飞行中出现未知静止障碍 → 雷达停车 → 重规划 → 绕行到达 → 降落清理。

- 该入口固定为无窗口模式；下方任何 `Display mode` 都不改变它。
- 每次启动重新核验重复测试证据链；按钮开放不等于跳过启动核验。
- 停止用同一卡片的 `停车并降落`。等待降落、解除武装和清理完成，不要直接杀进程。
- 用户请求停止可能在任务列表显示 `failed`，须结合 `job stopped by request`、工作流 `stopped` 及降落回执判断；不能当作完整路线成功。
- 顶部遥测属于本入口；下方历史地图轨迹可能属于另一流程，不能当作当前轨迹。
- 规划采用实时雷达与已知静态地图，视觉模型仅旁路，无飞行控制权。
- 已验收固定可行布局的 6 次正向、1 次安全拒绝，以及桌面启动完整飞行和空中主动停止。原窄布局仍不可行；不代表任意地图、运动障碍或真机安全认证。

## 常见问题

- **按钮禁用**：检查是否 Development、是否有任务运行、地图是否有效、实时避障门禁是否完整。查看日志，不绕过门禁。
- **有窗口模式没有窗口**：先确认启动的是普通场景或自定义地图入口，且对应控件选择了 Visual Preview；实时避障入口目前固定 Headless。
- **环境或端口冲突**：停止自己启动的旧任务并等待清理，不批量终止不明进程。
- **App 移到其他电脑**：仍需要配置仓库、Python、PX4、Gazebo 和模型依赖，不能只复制 App 就完成仿真环境迁移。
