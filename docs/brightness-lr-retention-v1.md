# 亮度增强条件下的学习率能力保留对照

本轮在已完成的亮度增强对照后，只将 AdamW 的恒定学习率从 0.001 降到 0.0005。不把学习率预先视为已证实病因，不同时搜索其他值。

独立目录为 `brightness-transfer-control-v1/brightness-lr-retention-v1`。复用上一轮三个亮度增强终点权重作为同 seed 参考，新训练 seed 7、17、27，全部从 v2.11 独立初始化。每单元 CPU、640 输入、batch/nbs 6、450 优化步、无预热、终点 last.pt；其余配置不变。

逐次成员、批次及批内顺序、完整标签、谱系曝光、每次亮度增益均与上一轮精确相同。继续使用原亮度哈希版本，不重新抽取增强。真实加载器逐 seed 遍历 2700 次曝光，核对完整标签、增强前后像素哈希与旧预检完全一致；禁止预检创建优化器、反向传播、训练或验证。逐单元恢复重新核验输入及完整回执，最多三次技术尝试，不拼接不可验证状态。

主比较为 0.0005 对 0.001 的同 seed 结果；旧无增强组仅作上下文。固定使用已查看的 48 张配对开发图、48 张无目标开发图和已冻结的 47 张训练拟合诊断子集。正式/诊断 confidence 为 0.37/0.001，CPU、640、同类 NMS IoU 0.7、max_det 300、同类一对一匹配 IoU≥0.5。逐框复核新误检、原始/光照电抗器与电容器组新增漏检及清晰训练目标漏检，不复用旧预测的审核决定。

保留全部既定数值门槛及相对 retained_reference-450、历史 A 的全图/逐类召回 5 个百分点容差。不挑 seed、不调整阈值，不以单 seed 好坏提前终止。三 seed 比较可以支持或不支持较低学习率有助于保留能力，不能确定唯一机制。
