# 整图暂缓对照：重点错误审核与定位

日期：2026-09-09。独立目录 `whole-image-hold-control-v1/error-localization-v1`。只审核，不改标签、不追加训练。

## 本轮覆盖范围

全部新增漏检按同图、视觉条件、完整真值annotation身份和坐标对应，冻结63个条目、80个seed事件。这不是63个独立场景。

本次实际查看背景条件全部新增漏检，以及原始条件电抗器/电容器组新增漏检：22个条目、27个seed事件。另查看两组无目标误检涉及的全部11张图，记录27个预测框的覆盖内容。共49条显式AI辅助审核决定，均绑定图像、证据、预测/真值身份与时间。

其余41个漏检条目保留具名待审核状态，没有生成通过意见。本次不是全开发集全目标的穷尽视觉审核。没有实例掩码，不认证像素级可见性；既有模型成绩已知，不称盲审。

## 定位一：确实包含清晰目标退化，不只是困难片段

重点22条中，7条主体清楚，11条有前景遮挡或仅局部，4条涉及图缘截断。

- **L059，原始电抗器，seed 27：** 大圆柱顶面、宽主体和基座清楚，仍从命中变为漏检；诊断输出有同类框IoU约0.941、置信度约0.003。不能归结为目标太小或不可见。
- **L010，背景电抗器，seed 17/27：** 同样是清楚的近处圆柱。两seed都存在同类低置信度框；背景更换后的性能损失不是仅发生在遮挡目标。
- **L060，原始电容器组：** 宽幅主体与基座清楚，有阴影。seed 7将其预测成变压器（置信度约0.910、IoU约0.822）；seed 17存在同类框，但置信度约0.212。说明同一实例可分别发生错类和分数不足，不能以一个原因概括。
- **L011，背景电容器组：** seed 7同样被高置信度预测成变压器；说明需要区分块状设备类别，而非只压低所有块体的分数。

另一方面，L054原始电抗器只露出柜体上方一段圆柱，最高同类IoU约0.445；L017背景电抗器被前方变压器遮挡，同类框IoU约0.495。这两项属于操作性定位不足，不与清晰大目标的分数退化混为一谈。

27个重点seed损失事件归为：**21个同类低置信度、4个错类、2个定位不足**，没有正式一对一匹配竞争。此分类受NMS及max_det约束；低阈值可见框不等于网络全部原始候选。许多分数远低于0.37，不能据此建议微调阈值，更不能在本轮改阈值。

## 定位二：误检减少，但混淆没有消失，还出现新类型

按相同无目标图和seed，原有17个误检帧事件中13个消失、4个保留，另外新增4个，总数变为8。不是所有原有误检都稳定消失。

| 事件 | 已查看的框内内容 | 本轮变化 |
|---|---|---|
| N03 | 远处灰块体侧背面、窄面板与底座 | 三seed原有误检均消失 |
| N05 | 黑杆、后方灰块体和旁侧蓝块体重叠 | 策略seed 7/27新增电抗器误检，置信度约0.898/0.896 |
| N07 | 多数框为灰色面板块体；参考seed 7另有一个蓝色小块体框 | 策略仍有变压器误检，seed 27新增电抗器误检 |
| N08 | 灰色正面面板块体及底座 | 仍有电容器组误检，seed 27变为电抗器误检 |
| N10 | 右图缘灰块体、底座和地面局部 | seed 17原误检消失，但策略seed 7新增电抗器误检 |
| N06 | 左图缘围墙—天空—地面交界 | 原seed 17开关柜误检消失 |

“灰块体”“柜状”是视觉描述，不是本次核实后的仿真资产名称。本轮没有重读这些负例的世界资产映射，资产身份明确保持unknown，不能将建筑擅自改称柜体。尤其N05不能只按整帧主题判成杆体或柜体。

## 支持的解释与尚未证明的机制

已证实：该替换策略降低当前无目标FPR，同时损失一部分清晰正目标，剩余混淆中还出现高置信度电抗器误检。它不是单纯“模型整体更谨慎”就能解释，也不是所有错误都由遮挡标签造成。

支持但未证实：整图替换带来的监督组成变化，可能影响类别区分及正目标置信度。每seed电抗器实例曝光减少97次，电容器组减少46–52次，开关柜增加128–140次；但曝光计数本身不证明因果机制，开关柜增加曝光后也仍有背景漏检。

不能据此宣布优化步数不足、模型结构不行、颜色是唯一根因，或删除四图必然有益。不能把误检类别从电容器组变为电抗器当成解决了误检。

## 下一优先方向

优先制定**完整实例监督曝光受控的替换对照可行性方案**：保持四张风险图暂缓，不恢复或删单框；检查现有合格成员能否在固定预算、负例曝光和来源约束下，避免明显削弱电抗器/电容器组监督。先报告约束是否可同时满足、仍不可避免的类别和谱系差异，再决定是否做新的独立实验。不能假定有解，也不能把补偿后的组成变化包装成纯粹标签效应。

上述22个重点损失和N05/N07/N08/N10作为下一轮固定错误回归清单，不转入训练。其余41条未审核损失以及负例资产映射仍列为缺口；本次不采集、不训练、不调阈值、不晋升。
