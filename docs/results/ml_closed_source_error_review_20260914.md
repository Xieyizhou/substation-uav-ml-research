# 封闭设备来源对照：错误审核与 CPU 加速核验

本轮已完成错误证据整理和 AI 辅助逐框审核；未训练、未调整阈值、未修改历史标签。所有新产物 training_admitted=false、promotable=false，无开发候选通过。

## 加速结果

推理继续锁定两个并发模型进程、每进程实际 4 个 CPU 线程，并在模型初始化后核验线程数。此选择不直接推广到训练。

本次 44 张证据卡片采用两个 CPU 进程。相同重载输入复测：串行 1.287 秒，并行 1.035 秒，约 1.24 倍；输出字节完全一致。仅一次小批对比，存在缓存和执行顺序影响，不承诺所有阶段同比加速。

测速曾发现子进程未继承临时目录，以及 JSON 字段排序影响误检卡片文字顺序的问题。原卡片已恢复至冻结哈希，审核依赖链重新通过。旧 diagnostic-confirmation.json 的测速结论作废，以 diagnostic-confirmation-v2.json 为准；新版显式传递隔离输出目录，测试确认不改动已审核证据。

## 审核覆盖与主要判断

- 13 个无目标误检预测，涉及 8 张唯一图像、7 个来源位姿；重复 seed 不增加独立样本。
- 36 个条件—目标条目、39 个新增漏检事件；共 49 条明确 AI 辅助审核决定。
- 全部 720 个实例转换保留：341 持续命中、292 持续漏检、48 得益、39 损失，未只挑损失统计。
- 12 个条目的 RGB 内容归属仍不明确：E13、E21、E26–E32、E39–E41。均保留待定及完整评估分母，不能据此认证标签错误或像素级可见性。

3 个新增漏检存在一对一匹配竞争：E13/seed7、E26/seed17、E27/seed17。有正式阈值以上的同类重叠框，但分配给相邻真值，不应简单解释为没有框或置信度不足。保留原操作性分类，另附匹配分配证据；这不同于计划命中与全图匹配冲突。

12 个主体可辨识的损失事件仍然存在，其中 8 个低置信度、4 个错类。例如光照电抗器 E09/seed7，同类 IoU≥0.5 框置信度由 E 的 0.776 降至 M 的 0.110。因此，不能将本轮退化全部归因于图缘、遮挡或内容不明。现有证据尚不能区分训练未学稳与开发条件迁移受限。

## 与全量结果一致的结论

E→M：材质计划命中均值 0.4444→0.3611；光照 0.5278→0.5556；无目标帧 FPR 0.0694→0.0139。材质三个 seed 两降一升，不支持稳定改善。M 剩余两个误检来自同一张混合结构图，不可按两个独立场景计算。

两组均未通过既定数值门禁；内容审核不会改变这一结论。M 的误检减少是真实开发收益，但不证明已完成从颜色到结构识别的转变，也不能抵消材质及部分能力保留门禁失败。

## 下一优先方向

优先对已有 E/M 权重进行对应结构的训练成员拟合诊断：绑定实际曝光，先检查已审核、主体清楚的同类目标是否在训练侧仍低置信度或错类，再与开发侧配对比较。这样可区分“已有样本尚未学稳”与“训练侧学会但条件迁移受限”的支持性证据；此报告不自动启动新的训练或补采。内容归属不明条目继续独立保留风险，不作为新增训练批准。
