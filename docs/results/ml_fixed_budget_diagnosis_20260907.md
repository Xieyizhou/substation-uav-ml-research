# 固定有效曝光序列：100/300步预算诊断

## 结论

本次严格对照不支持把“训练步数不足”作为当前错误的充分解释，也不支持直接延长训练作为解决方案。300步略减无目标误检，却损失光照条件全图能力；材质计划实例命中没有提高。没有选择、替换或晋升模型。

这是单条固定有效序列、seed 7的预算诊断，不是三seed候选验收，不代表所有采样序列的平均效果。不能推断所有更长训练均无效，不能宣称已确定全部检测错误的唯一病因。

## 冻结设计与执行

- 复用最新已验证的CF-100-7端点；不是从历史结果中挑选有利参考。
- CB-300-7独立从v2.11初始化，将CF的600次有效曝光顺序完整重复三次。每个六图批次的成员、内部顺序及批次顺序不变。
- CPU、640、batch/nbs 6、AdamW、lr 0.001恒定、无预热、既有增强关闭；只评估预定终点last.pt。
- 实际完成300次优化、1800次图像曝光：基础池648、常规468、桥接360、困难负例324。其中沿用每600次曝光72旧负例、36新负例。
- 222个不同图像成员，160个谱系组；谱系组不等同160个独立新场景或已认证独立位姿。三遍曝光不增加独立样本量。
- 全图标签产生的类别实例曝光：变压器2139、开关柜2649、电容器组600、电抗器537。计划类别覆盖不等于全图监督均衡；该差异本轮未改动，不能单凭次数认定其为唯一病因。
- 实际采样与冻结计划一致；前100步对应的10轮CSV损失与参考完全一致。没有保存或比较300步运行中第100步的完整参数状态，不能把CSV一致宣称为中间状态逐位一致。

## 错误与拟合诊断

训练box/cls/dfl损失由第100步记录的0.70087/0.63523/1.08419降至第300步的0.43328/0.37663/0.92071。训练拟合改善，但开发收益不一致，出现能力取舍；训练成员末轮验证不能作为泛化证据。

材质组漏检中：同类低置信度20→7、错类17→18、定位不足1→4、无满足条件的保留预测0→8。光照组分别为18→12、7→13、1→2、0→3。低置信度类型减少并不等于漏检被解决，部分结果向错类及其他失败类型转移。分类受NMS与max_det限制，最后一类不表示网络未产生任何候选。

本轮没有对新增300步误检框做内容级AI复审，不能把上一轮“柜体/建筑”审核直接套用于这19个框。

## 下一步解决路径

1. 暂停单纯追加训练步数，不使用300步权重替换参考，也不临时改变阈值。
2. 优先复审本轮新增/持续误检及光照开关柜丢失实例，按框内实际内容、目标像素尺度和对比度与既有训练覆盖对照。先区分监督覆盖缺口与已有结构未学会，不能依据帧主题给框分类。
3. 在现有已审核训练成员中设计一个预先冻结的“实际混淆结构覆盖”采样对照，锁定总预算、共同正样本位置及有效批次顺序；完整记录类别实例曝光。若确有未覆盖结构，再单独申请有针对性的补采，不能将当前开发图或其派生图收入训练。
4. 只有在覆盖充分仍持续失败时，才另立单因素的外观增强或优化器稳定性对照；不同时改采样、增强、学习率与结构。当前没有证据优先换大模型。

这是由当前项目实验得到的待验证推进方案，不是已验证能解决检测错误的保证。
