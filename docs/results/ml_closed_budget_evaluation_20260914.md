# 450→900步：评估、逐框审核与最终判断

## 判断

**增加完整训练预算带来明确的开发收益，但伴随电抗器能力取舍，未通过全部既定门槛。** 不选择开发候选、不晋升、不追加训练步数。

六模型均完成正式/低阈值推理，48条AI辅助逐框审核已填写；5个条件—目标条目的内容归属仍待定。这表示评估和审核流程完成并公开缺口，不表示所有监督问题解决。

## 可比性与执行

B450、B900各seed7/17/27，均从v2.11独立初始化。同seed前450步成员、完整监督、亮度张量和损失记录完全一致；900步再重复整个2700曝光序列。CPU640、batch/nbs6、AdamW、LR0.0005恒定、无预热、仅冻结亮度不变，只评估终点last.pt。

这比较的是完整预算翻倍：原始、材质、负例及各类实例曝光全部变化，不是纯材质增曝或纯负例因果实验。当前B450是相同CPU执行配置下新训练的对照，不用上一轮M成绩替代它；不同线程配置不保证训练终点完全相同。

开发集为已查看48张配对图、48张无目标图。CPU640、confidence0.37/0.001分别推理，同类NMS IoU0.7、max_det300、同类一对一匹配IoU≥0.5。六模型1152次预测调用（不含预热）采用双进程、每进程实际4线程，约80.1秒；45张证据卡双进程生成约0.96秒。没有新增训练或阈值调整。

## 能力取舍及门禁

原始电抗器召回：80→60%、100→80%、60→80%，均值下降6.67个百分点；光照电抗器：60→20%、40→40%、20→40%，均值也下降6.67个百分点。两者超过相对本轮B450的5个百分点容差。原始/光照其他类别均值没有超过该相对下降容差，但不能抵消电抗器损失。

B900仍未达到材质均值50%和光照均值60%；此外相对固定retained_reference-450及历史A存在能力保留失败，包括原始开关柜、电抗器等。详细失败项保留在summary.json。历史函数的`same_budget_R`字段名实际指冻结retained_reference-450，**不是新训练的900步R组**；audit.json已明确说明。不得因接近阈值放宽门槛。

本批以12个位姿组描述配对独立性，三个seed不是新增独立场景。材质计划命中提高8.33个百分点而全图只提高1.11个百分点，说明收益较集中，不能声称完整结构识别已普遍增强。材质电容器全图召回三seed均仍为1/6；材质开关柜均值还略降2.15个百分点。

## 逐框审核和匹配核验

查看12页全图与独立目标/误检裁剪，记录48条AI辅助审核（时间、具体理由、图像/标签/预测/证据身份绑定），无实例掩码可见性认证。

- 720个实例-seed转换全部保留：311持续命中、288持续漏检、75得益、46损失。
- 46损失事件对应41个条件内目标条目，全部四条件均覆盖，非只查看原始/光照损失。
- 7个无目标预测涉及4张唯一图像、3个位姿；B900的两个误检分别是灰边深色面板和图缘青色柜状块体。视觉外形不代替仿真资产身份。
- 5个待定条目：E07、E12、E15、E23、E33；主要是相邻柜体重叠、图缘或前景遮挡造成内容边界不明。继续保留在全量指标中，不删标签、不自动通过。

操作性漏检分类为34低置信度、10错类、1定位不足、1未发现合格保留预测。其中E12/seed7、E15/seed7、E33/seed17涉及正式高置信度框分配给相邻真值的竞争，audit.json保存预测和分配证据；排除这3个竞争事件后为32低置信度、10错类、1定位不足。最后一类原始操作性标记不解释成网络没有产生候选。

计划命中与全图一对一分配冲突为0，与上述非计划相邻实例的匹配竞争不是同一问题。原始标签和指标未被修改。

损失并非全由难辨目标造成：E05材质圆柱、E06光照圆柱、E26灰色柜体、E41灰色柜体背面、E43/E44宽电容器箱体均有可辨主体。其中既有低置信度也有错类。另一方面，原始电抗器新增损失中有前景遮挡及图缘截断，不能把所有损失都宣称为清晰完整实例的遗忘。

## 下一优先方向

**优先核对本轮B450/B900的电抗器训练成员拟合与开发损失对应关系，而不是继续加步数。** 用实际曝光、固定身份和内容分层区分：训练侧同样退化，还是训练拟合保留而开发条件退化。该核对可复用现有权重，无需立即补采或再训练；之后才决定能力保留采样对照或条件迁移对照。

已证实的是完整预算增加带来部分收益与类别取舍；尚未证明唯一原因、跨场景泛化或“从颜色转向结构”的完成。所有产物training_admitted=false、promotable=false，新场景仍封存。
