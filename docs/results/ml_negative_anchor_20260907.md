# 旧负例曝光锚定对照：重要判断

结论：本轮完整完成，但未支持预先固定的采样改善判断，也未产生开发候选。到此停止，不追加临时配比或挑选seed。

## 实验冻结与执行

- 独立目录：hard-negative-coverage-v1/negative-anchor-v1。
- H组每600次曝光：基础216、常规156、桥接120、旧负例72、新负例36。24张旧负例各3次；从对应N已使用的新位姿对中按固定seed抽18对，两种光照各一次。新图不按模型成绩选择。
- 固定seed 7/17/27，三个独立100步训练，共300优化步、1800图像曝光；实际序列全部与计划一致。与O/N的正样本成员、顺序、曝光位置及类别实例监督不变。
- v2.11初始化，CPU/640/batch6/AdamW/lr0.001，无预热、恒定学习率、增强关闭；使用预定last.pt，不用best.pt选择。末轮训练成员验证仅为拟合诊断。
- 正式开发集仍为48张配对图及48张无目标图；conf0.37，类别相关NMS IoU0.7，max_det300，同类一对一匹配IoU≥0.5。配对图另保留conf0.001漏检诊断。本轮未额外运行无目标低阈值推理或新的逐框内容审核。
- 先验判断：相对N，FPR均值降低且至少2个seed降低；原始/光照全图及每类召回均值下降不超过5个百分点。候选另须通过全部既有绝对指标及相对R/A保留门禁。

固定108次负例预算无法同时保留旧负例108次并学习新负例。因此本轮是72/36的部分恢复，不是完全恢复；解释为负例组成和重复曝光重新分配的整体效果，不能隔离唯一因果。

## 下一重要判断与建议

已经到达用户要求的判断点：恢复部分旧负例曝光带来原始/光照能力恢复，却没有稳定降低误检，且材质/背景全图召回出现取舍。不能继续把“旧负例曝光不足”当作已证实的单一根因，也不应依据seed7单独宣布成功。

下一阶段建议先分析H三个seed的新增/持续误检类别、实际结构、实例尺度及末轮损失走势，与O/N逐框对应；区分外观背景特征取舍与优化波动。此前N的审核不能代替H的框内审核。先完成这项诊断，再决定固定一种增强或优化过程对照，不继续盲搜负例配比，也不直接更换模型架构。暂不扩大补采。
