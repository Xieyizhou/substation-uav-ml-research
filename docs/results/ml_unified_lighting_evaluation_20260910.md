# 统一暂缓与物理光照对照：开发评估报告

## 结论

六个终点权重的正式、低阈值评估及本轮错误审核已完成；状态为 `evaluation_complete_with_named_gaps_no_candidate`。两组均未通过全部数值门禁，另有10个目标的像素归属证据不足，保留具名待定。不选候选，不晋升，不解封新场景。检测流程完成不等于所有数据问题已解决。

物理光照组提高了光照条件计划命中均值，并降低无目标误检均值，但未形成稳定的整体能力改善：原始条件电抗器召回下降，材质条件仍不达标，背景计划命中下降。结果支持存在条件收益与原有能力之间的取舍，不支持“光照是唯一病因”或“继续增加相同光照曝光即可解决”。

## 本轮逐框AI辅助审核

全量查看8张唯一误检图的15个预测框，以及19张图上41个唯一新增漏检目标的全图和放大图。新增漏检覆盖两组相对上一轮brightness对照，另覆盖L对同seed R的损失；保存得益、持续命中与持续漏检全部状态。

审核结论绑定本轮图像、裁剪、叠框页、预测/真值和评估输入哈希，标为AI辅助审核并有时间、理由。不继承历史通过决定，不修订历史标签。

- 误检主要是灰色块体正面/侧面、青色带面板柜状块体及灰块与杆体重叠；FP06的一个框主要覆盖地面网格及杆影。不能按整帧有杆就将所有框归为杆体。
- FP07同一灰块被同一seed以两个类别重复预测，类别相关NMS保留这种跨类重叠；这不是两件独立结构。框内视觉外形和资产身份分开：本次RGB审核不把灰块重新命名为已解析的仿真柜体资产。
- 71个去重后的“训练单元×新增漏检目标”事件中，60个为同类低置信度，7个错类、2个定位不足、2个未发现合格保留预测。不同参考比较出现的同一漏检只计一次；这些也不是71张独立图片。
- LOSS02：清晰圆柱电抗器，L/seed17同类低阈值框IoU=0.9495、confidence=0.0290，正式漏检，无一对一匹配竞争。
- LOSS19：清晰近景电抗器，L/seed7同类框IoU=0.8370、confidence=0.2858，正式漏检。表明至少部分损失并非完全由遮挡或定位不准解释。
- LOSS39/41：电抗器上部被前景变压器遮挡，不能与完整圆柱证据混为同一可辨识条件。

具名待定：LOSS03、12、13、16、17、20、23、29、38、40。涉及重叠柜体的窄条带、图缘片段，RGB不能可靠认证具体实例的可见像素。历史 `truncation_status` 与视觉图缘接触分开保留，不把既有字段自动当成完整可见证明。不认证像素级可见性，也不直接宣布历史标签错误。

## 事实、解释与下一优先方向

已证实：冻结配置下，物理光照策略产生上述条件间取舍；存在清晰目标的同类高IoU低置信度漏检，不能只归因于微小目标或遮挡。三seed效果不一致，两组均不具备候选资格。

支持性解释：有限来源的光照处理改变了类别置信度与条件适配；可能存在能力干扰。但没有证明优化器、曝光次数或光照本身是唯一原因。低阈值受NMS及max_det限制，“未发现保留预测”不代表网络没有产生候选。

下一优先方向：先做独立的开发标签语义/可见性风险核对，仅处理上述10个具名目标，冻结原结果并明确任何勘误的影响范围；本阶段不修改标签。核对完成后再设计针对清晰电抗器低置信度的能力保留对照，不立即加曝光、不降低置信阈值、不凭本轮收益启动新训练。四个同源光照位姿不足以支持跨场景泛化或唯一病因结论。
