# 三个边缘标签来源审核

## 审核结论

T049、T054、T148均不是训练导出时新增或错位的框：训练PNG与原始PPM逐像素一致，训练标签与原始采集框的最大坐标误差均小于0.000001像素，仿真实例映射可唯一解析为开关柜。

问题集中在**极端边缘截断下，full_2d矩形框包含大量非设备区域，实际可辨识设备内容很少**。独立投影支持这一解释，但未进行渲染器复跑或像素实例掩码验证，所以仍不能把它们认证为合格可见目标，也不将其直接定性为错误标签。本轮维持待定、不改标、不删除、不训练。

## 标注模式与回执边界

保存的三个plan均声明full_2d；各自world.sdf实际相机box_type也都是full_2d，世界文件哈希与计划一致。没有发现模式声明与保存世界不一致。

T049/T054来自早期schema v1采集回执，没有actual_annotation_mode或check_version字段。这些缺失不能通过本次读世界文件补写成历史运行时语义门禁已通过；本次能验证的是保存文件及几何与结果的一致性。

T148有actual_annotation_mode=full_2d和canonical-collection-gates-v2。它仍出现附带极端边缘框，说明当前计划实例存在性门禁不等于所有全图框的可辨识性门禁。仅修复计划目标检查不能解决这一类训练监督问题。

## 投影如何核对、不能证明什么

读取保存世界中每个实例的base/body/front_panel盒体几何、实际载体姿态、research_camera_link偏移与RGB水平视场角；以独立针孔模型投影盒体角点，求二维凸包并裁切至图像。

不考虑遮挡时，各视觉几何投影面积之和与原始矩形框面积之比约为11.92%、14.71%、6.91%。这不是可见像素比例：视觉几何之间可能重叠、未扣除遮挡，并且未使用实际渲染实例掩码。这些数值只能说明“矩形框存在”远不等于“框内有足够设备内容”，不能当成新的自动准入阈值。

T054/T148即便几何投影允许基座片段进入画面，也不足以从RGB可靠辨认开关柜主体。因此不把它们直接作为“合法截断已通过”的结论；反过来，也不因框里大部分是地面就武断认为标签映射错误。

## 处理建议与下一步

1. 保留原始文件与历史结果，三项继续待定；不将整幅含其他目标的图改为空标签，不直接删掉某个框以免制造未标注目标。
2. 在新版本数据处理规则中明确“仅基座/不可辨识极端截断”如何处理。优先用受控重放的实例可见像素掩码或独立几何/深度核对解决可见性，再决定整帧暂缓、替换位姿或采用明确的忽略区域策略。当前训练器并未因此获得忽略区域支持，本轮不实现这些变更。
3. 相同规则还需回查剩余待定项和全图非计划实例，不能只对这三个已发现框做例外清理。
4. 规则和新版本审核冻结后，才做监督质量对照；不把其潜在收益预先认定为材质错类的完整解决方法。
