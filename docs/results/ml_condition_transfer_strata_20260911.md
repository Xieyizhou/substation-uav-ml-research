# 四条件可辨识性分层迁移核对

## 结论

在同一 `pair_id`、同一设备实例和同一相机位姿下，将已完成的几何/遮挡分层传播到原始、材质、背景、光照四个变体。四个变体的类别、实例编号和真值框坐标逐项一致，因而这一步没有把几何变化误认为外观变化。

最重要的结果是：**材质条件是当前开发集上最稳定、最强的退化因素。** 这不是由图缘或遮挡分层差异造成的，因为四个变体共享同一几何与可见性分层。

## 清晰目标三 seed 合并结果

| 训练家族 | 原始 | 材质 | 背景 | 光照 |
|---|---:|---:|---:|---:|
| R-clean | 47/51 = 0.922 | 21/51 = 0.412 | 47/51 = 0.922 | 31/51 = 0.608 |
| L-physical | 45/51 = 0.882 | 20/51 = 0.392 | 45/51 = 0.882 | 40/51 = 0.784 |

材质相对原始条件的清晰目标召回下降：R-clean **−51.0 个百分点**，L-physical **−49.0 个百分点**。六个 seed 的材质清晰目标召回均低于原始条件，范围为 R-clean 0.294–0.529、L-physical 0.353–0.471；方向一致但样本来自单一复杂布局，不能宣称跨站点泛化。

背景条件的清晰目标召回与原始相同；其主要影响出现在 `partial` 与 `fragment`，说明背景变化和遮挡/内容层次存在交互。光照条件在两个家族之间波动较大，不能与材质退化合并成同一个原因。

## 事实、解释与限制

- 四条件间几何、实例身份、类别和框坐标均通过逐实例核对；传播的只是“可见性/内容分层”，不是重新审核材质颜色下的可辨识性。
- 材质差异保持了原有几何和相机，因此支持“训练外观与材质条件不匹配”这一优先假设；不能单独区分材质曝光不足、颜色依赖、面板对比变化或优化不足。
- 当前结果复用了已有六个训练单元和已查看的开发集，不新增数据、不训练新权重；完整全量指标仍作为正式结果保留。
- 不能据此调整置信度阈值、删除材质失败图或声称模型已经通过。

## 下一步出口

优先冻结一个**来源隔离的材质覆盖对照**：只增加已审核材质变体的训练曝光，保持原始/背景/光照评估和无目标 FPR 门禁不变；同一批次、相同初始化、三个 seed、固定终点权重。训练前先完成成员、曝光、谱系和完整标签预检。

如果材质覆盖对照改善材质且原始/背景/光照能力保持，支持继续扩大材质覆盖；如果只改善当前布局，则转向资产/布局多样性；如果材质召回不变，则优先检查颜色依赖、标签内容和优化设置。当前阶段不执行这些训练变更。
