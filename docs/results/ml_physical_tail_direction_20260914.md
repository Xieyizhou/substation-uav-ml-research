# 尾阶段退化分析与下一优先方向

## 结论

下一步优先做**同seed双向BN运行统计替换诊断**，先分析、不优化参数；暂不追加低光图、不增加训练步数、不直接以本轮权重继续训练。

已能定位到需要测验的机制层面，但不能宣布唯一根因。两组共同的窄来源尾阶段比低光因素更值得优先排查；BN运行统计偏移和参数能力干扰仍需分离。

## 新增只读证据

已重新校验冻结设计、完成回执、实际曝光和九份本地终点权重身份。六个新单元前900步逐项损失与同seed B900完全一致；前次审计另确认输入及完整标签一致。

第801–900步的600次曝光含基础池210–225次、常规148–163次、负例96–115次；第901–1000步的600次全部变为桥接正例。常光组仅32张图、低光组64张派生图，但都是同8个位姿，不能把图数增加称作场景独立性增加。

六个单元第901–950步分类损失均值为0.211–0.233，第951–1000步为0.127–0.146；框损失也下降。这里只表示尾段记录损失下降，不表示所有训练成员已学稳，也不能比较不同组成窗口的绝对损失来证明泛化提升。结合开发集下降，支持存在适应尾段分布但未保留原能力的风险。

最后50步300次图像曝光的完整实例曝光并不类别平衡：seed7为变压器122、开关柜230、电容器78、电抗器64；seed17为102/228/78/78；seed27为108/240/82/66。R/L同seed完全相同。计划类别配额不能代表全图监督配额；这些数字本身不足以证明类别不平衡是根因。

九份终点张量均为有限值。各新终点相对B900的81组BN运行均值、81组运行方差全部改变：均值组相对L2差为8.78–11.98%，方差组15.49–17.43%；其他浮点状态组为2.59–2.80%。不同张量组的尺度和语义不同，不能按这些百分比排序因果重要性，也没有以此设置门槛。

本机实际训练器实现会训练未冻结的BN，并把浮点状态（含BN运行统计）纳入EMA；保存EMA，最终strip流程将EMA置于model字段并清除优化器。评估读的是终点last.pt，不是按开发成绩挑选的best.pt。未发现这些检查覆盖范围内的非有限张量或导出对象选错证据；未证明整个框架无缺陷。

该分析只读取既有权重，没有模型参数修改、前向推理、反向传播、训练验证、标签修改或新数据采集。

## 固定判断出口

- 若R参数＋B统计在三个seed原始/光照召回均有恢复，同时B参数＋R统计三个seed均退化，且误检方向一致：支持BN统计参与退化，下一训练对照优先验证尾段BN处理策略；不宣称统计是唯一原因。
- 若R参数＋B统计未出现一致恢复：不能据此排除BN（参数和统计可能共适应）；下一优先比较保留基础/负例的交错复习与集中尾段，预算及曝光多重集固定，测试时间分布效应。
- 若两个方向结论混合或类别收益伴随损失：保留交互与取舍，先做机制分析，不按有利seed下结论，不继续临时试更多统计组合。
- 若身份、未融合模型或原模型复现失败：先修复独立诊断入口，不开始模型对照解释。

本轮要求是分析直到得到下一方向，至此已满足；以上替换及补推理尚未执行，需要进入该独立诊断阶段。未把提出方案写成已证明机制。
