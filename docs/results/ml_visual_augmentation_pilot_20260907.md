# 240 张数据增量方案与流程 pilot（2026-09-07）

已冻结 `visual-augmentation-240-v1`：144 张材质/光照正样本候选、48 张困难负样本候选、48 张常规正样本候选。账本的 240 条候选记录对应 96 个独立位姿/派生组（材质光照 24、困难负样本 24、常规正样本 48），不会把同源变体当成独立场景。

现有 48 张配对实验被登记为固定开发回归，明确“不入训、非盲测”。Extreme 新布局测试计划在训练前封存为 16 个正样本和 8 个计划负样本；开发对照选定候选前不采集、不评估。Extreme 物化时发现实例标签哈希碰撞，默认门禁正确拒绝；新测试计划使用单独记录的确定性线性探测解析，历史标签身份未修改。

20 帧流程 pilot 按计划先运行两组电容器/开关柜正样本。8/8 张通过采集门禁并保持待审核，未自动准入。第一张困难负样本被语义门禁拒绝：视角以普通柜体为主体，但全图同时包含 transformer、switchgear 和 capacitor_bank，因此不能写成空标签。拒绝帧和原因已保留；技术重试没有将其静默放行。

该结果说明流程门禁有效，也说明当前 24 个困难负样本位姿不能直接展开整批采集。`visual-augmentation-240-v1` 保留为首版冻结矩阵及失败证据；下一版本应重新设计全图无目标构图，优先使用隔离背景世界或经预采 truth 验证的建筑、围墙、杆塔与柜体视角。两种光照必须共享同一合格负样本位姿。正样本也应完成逐图 AI 辅助审核和账本回填后，再决定是否沿用首版 144/48 正样本计划。

未开始任何 A/B/C/D 训练，未开启 Extreme 测试集，未修改现有 48 张回归集；所有产物仍为 `training_admitted=false`、`promotable=false`。
