# 新旧标注兼容性核验

后续实采结果见 [2026-09-06 配对标注校准](ml_paired_calibration_20260906.md)：62 次采集已完成，同图对照证实模式范围差异，19 帧继续暂缓。

结论：不能将 canonical 可见边界框直接当作旧样本的同类标注混入训练。上一步 445 张是暂定合并数，本次进一步拆为 **426 张待后续准入的候选 + 19 张目标标注范围待确认样本**。另有上一步单独保留的 23 张未完成采集批次样本，未计入这两个数。训练仍未启动。

## 已证实的差异

| 项目 | 419 张旧候选 | 26 张 canonical 增量 |
|---|---|---|
| 目标框数量 | 964 | 46（分布在 19 张目标帧中） |
| 含非整数坐标的框 | 964 | 0 |
| 可见范围状态 | unknown | visible_extent_only |
| 存储坐标约定 | 半开坐标 | 经显式适配后的半开坐标 |
| 采集模式证据 | 历史运行配置未完整绑定 | 相关计划的 world.sdf 明确为 visible_2d |

当前 `simulation/models/x500_research/model.sdf` 设置为 `full_2d`。这是当前配置证据，不能据此证明每次历史采集都使用了这个版本；浮点坐标也不能单独证明历史传感器模式。

已有适配器对可见像素框的右、下边界加 1，解决的是“包含末端像素”与“半开坐标”的表示差异。它不恢复被遮挡部分，也不能证明框覆盖的物体范围与旧标签一致。直接把两批数据混用可能让相似画面收到不同范围的框监督；此风险尚未通过配对实验定量测量。

因此，本次将 19 张目标帧完整保留到 `canonical-scope-hold.json`。7 张已复核的背景帧没有目标框，不存在这项目标框范围差异，加入 419 张旧候选形成 426 张后续检查清单。所有样本继续受既有配额、来源隔离等准入门槛约束，没有宣称旧候选或背景增量已经通过训练准入。

## 柜体类别核对

四类映射仅包含 transformer、switchgear、capacitor_bank、reactor；普通 cabinet 不在其中。上一步读取的场景快照明确将柜体与开关柜定义为不同类别。因此，画面中的柜体没有目标框不能自动判为漏标。

源码同时表明两者外观接近：例如 Medium 的 entry_switchgear 与 cabinet_west 使用相同底座尺寸和箱体平面尺寸，箱体高度及颜色不同。这是值得验证的可辨性问题，不是已经证实的错标或模型失败因果。保持四类定义，不把普通柜体直接改标为 switchgear。

## 下一步可执行校准

已生成 `paired-calibration-specification.json`，绑定 19 张目标图像、视角与计划身份：

1. 固定场景和相机位姿，对照 full_2d 与 visible_2d；按实例编号匹配全部目标，分别记录端点转换和物体范围差异。
2. 对三张地图中的 cabinet 与 switchgear 做同距离、同角度、同照明的正面/侧面比较，绑定源对象编号，保留尺寸与材质证据。
3. 校准完成后决定统一标注范围及如何处理外观相近的非目标柜体，再恢复未完成采集并更新补采需求。

本轮完成的是核验、分离清单和配对校准规格，未执行新的仿真采集或模型推理。历史传感器配置、保护录制/轨迹来源的缺口继续保留。
