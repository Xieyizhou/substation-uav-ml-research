# 历史标注来源与后续统一规范

对当前 419 帧旧候选涉及的 35 个采集批次，逐一读取 collection-receipt、run-receipt、可用的 prearm 记录及原始 truth.jsonl。原始真值哈希全部匹配采集回执。25 个批次的原始真值带有 xyxy_pixels_half_open 坐标约定，显式 full_2d / visible_2d 模式证据为 0 个批次。坐标约定与标注范围是不同属性，不能互相推断。

当前传感器源文件及配置加载器要求 full_2d，这只能证明当前实现意图；现存上述历史回执没有绑定当时实际加载的传感器快照，不能据此认证历史范围。此次没有读取受保护集标签，也没有认证历史评估集或 replay 的标注范围。

## 后续采集规范 v1

- 后续完整范围恢复分支使用显式 full_2d；visible_2d 保留为独立诊断分支，两者禁止直接混合。此规范不追认旧数据，也不更改冻结基线评估口径。
- 每批绑定世界、传感器、类别映射、转换器版本及其 SHA256；回执明确写入 annotation_mode 和 bbox_coordinate_convention，并证明实际加载的是所绑定快照。
- full_2d 保留原始浮点框；visible_2d 的 inclusive→half-open 转换仅改变端点约定。禁止用扩框或取整推断被遮挡的完整范围。
- 保留原始真值和全部实例；存在边缘截断、缺失实例或范围不确定时整帧隔离。普通 cabinet 仍在现有四类之外，不根据外观相似擅自改成 switchgear。
- 合并前必须验证图像身份、标注范围、类别映射和转换一致；随后仍须通过既有去重、来源隔离、语义与覆盖准入。仅完成来源核验不等于允许训练。

以上是恢复分支的规范文件，尚未接入通用训练 CLI 的自动门禁。现有 426 帧候选全部保持 pending，19 帧范围暂缓及 23 帧不完整采集暂缓继续保留；没有修改标签或启动训练。
