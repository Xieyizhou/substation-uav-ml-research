# 多尺度开发错误排查：结论与下一方向

## 完成范围

读取六份有效正式／低阈值推理，重新校验配对真值及已纠正的逐框设备身份，不用计划目标ID替代非计划设备。按pair_id、variant、类别与坐标核对；在对应帧内匹配唯一真实设备身份。

保存全部720次seed–实例得失记录（240个真值×3seed），包括得益、持续命中和持续漏检。它们不是720个独立样本。逐图查看7张证据页，包含27个事件卡：多尺度全部8个无目标误检框、原始／光照全部新增漏检及材质电抗器新增漏检，共22个不同帧内真值框。30条明确AI辅助审核决定已保存；E08、E13、E17因邻柜遮挡、截断和像素分界不足保留待定。不修改历史标签，不认证实例像素级可见性。

## 已确认的错误表现

### 光照损失主要表现为置信度下降，而非普遍定位偏差

原始条件新增漏检5次，光照22次；次数按seed–实例计算。光照四类操作性分类：同类低置信度16、错类3、定位不足1、未发现合格保留预测2。其中后一类有1次实际存在高置信度同类预测，但发生全图一对一匹配竞争，不能描述为没有候选。

16次低置信度中11次的最高同类IoU≥0.5保留框低于0.12。清晰近景变压器E07在seed7由0.9553降至0.0098，seed17由0.8076降至0.0087；端子、主体、基座在RGB中清楚。说明错误并非都来自微小、完全不可辨目标，也不是仅略低于0.37。低阈值输出有NMS及max_det限制，不等于网络所有候选。

### 有跨seed复现的类别混淆

E11同一光照电容器组在三seed由命中转为漏检，同时被预测为变压器，置信度0.872、0.883、0.657，框IoU分别0.968、0.957、0.945。视觉上顶面、宽侧面和基座可辨，左下部分被前景柜体遮挡；这是重复测量的一个实例，不是三个独立结构。材质电抗器另有三个新增损失事件：两个低置信度，一个错类；其中E24主体和基座清楚。

### 无目标误检不是本轮的“杆体问题”

8个误检框分布于5张唯一图像、4个view_id：6个覆盖青色柜状块体（正面面板或侧背面），1个覆盖灰色块体正面面板与基座，1个覆盖后方灰块下缘／基座及前景青块混合结构。没有一个主要框住独立杆体。这里只描述视觉外形，不把仿真建筑资产重新定名为柜体。

seed7产生7框，seed17产生1框，seed27为0。E01同seed两个框覆盖同一青色块体；E04/E05为同view不同光照的对应青块。E05虽跨seed同图出现，两个seed框住的是不同结构，不能声称跨seed一致混淆同一物体。最大误检置信度约0.938，进一步说明统一降低阈值不是稳妥解决方法。

## 匹配与监督边界

E08（光照seed7）和E17（原始seed17）同类框置信度分别0.886、0.925，覆盖所考察真值IoU约0.646、0.647；它们以更高IoU分配给邻柜。保留原四类诊断标签，同时用formal_matching_competition单独标识，不将其归因为单纯置信度不足。此前“计划命中冲突为0”只指计划目标独立命中与分配命中一致，不表示全图没有匹配竞争。

E08、E13、E17的RGB实例像素归属仍待定。清晰变压器E07和跨seed错类E11不依赖这些待定柜体，因而支持部分结论，但不据此宣布所有监督风险清除。既有评估及历史标签保持原样。

## 解释与下一优先方向

事实：宽范围多尺度获得原始／背景收益，同时在光照发生明显的置信度与分类取舍；这不是简单的“没有训练成功”，也不是普遍定位不足。支持性证据：当前尺度策略对条件间能力存在干扰。尚不能确定是320端、960端、非640曝光占比、优化预算，还是它们与亮度增强的组合造成；不能直接归因于某个尺度或唯一根因。

下一优先方向是先设计**尺度端点分解的单变量对照**：在保持同一成员、批次、亮度系数、LR、450步及三seed不变时，分别检验仅加入小尺度和仅加入大尺度的策略；固定640继续作共同参考，各组非640曝光比例须相同且预先冻结。仍从v2.11独立初始化，不沿用本轮较有利seed，不同时更改光照增强或阈值。具体比例先做可行性与真实加载预检，本次不冻结新实验、不训练。

理由：先拆开当前混合尺度干预，才能判断哪一端保留原始收益、哪一端引入光照损失；直接换“温和尺度”会把范围与有效曝光同时改变，病因解释较弱。待定邻柜应独立登记，不为优化结果删标签或排除全量门禁。
