## 接续方式

先查看运行中的 `python -m scripts.vision.run_visibility_quality_training`，存在时不要重复启动。检查各 Q-* 的 completion.json、evaluation-Q-*.json及最终completion.json。进程结束且无完整回执时先查失败记录，不能直接清空重跑。旧运行会顺序推进剩余单元并自动评估、汇总。

本轮结束后，验证全部输入、权重、实际曝光、100/300前缀、相关测试及v2.11固定40文件。若未通过，先总结误检下降是否以原有召回损失为代价、全图类别曝光是否仍失衡，再冻结单一下一步干预。可自主补采，但必须独立来源、相机合法、实例与全图标签核验、逐图AI辅助审核和谱系分组，不用开发成绩换图。

持续跟进机制依据 OpenAI Docs 核对后采用：[官方闭环与 heartbeat 说明](https://developers.openai.com/cookbook/examples/agents_sdk/agent_improvement_loop#step-9-close-the-loop)。这不会替代实验门禁，也不保证模型最终达到目标。
