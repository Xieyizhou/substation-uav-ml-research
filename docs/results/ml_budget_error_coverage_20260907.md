# 300步错误逐框复核与训练覆盖判断

## 重要判断

优先做已有负例的分层覆盖采样对照，而不是继续延长训练或马上补采。当前证据同时存在两种问题：部分专门子类在有效序列中没有曝光；占主导的建筑混淆结构已经曝光，却仍然误检。因此不能把全部错误解释成“没见过负例”，也不能保证补齐柜体采样就解决主要问题。

本次新增工作只包括开发诊断和AI辅助审核，没有训练、修改历史协议、补采或解封测试。

## 逐框审核结果

查看了300步模型无目标开发集的全部19个预测框（17张图），以及相对100步新丢失的全部8个光照真值框。预测框裁剪由原尺寸图生成，记录图像、预测坐标、置信度、证据图哈希与逐项理由，统一标记AI辅助审核。

19个误检框实际内容：建筑15、混合结构3、普通柜体1。建筑框主要覆盖灰色立面、大暗面板和基座；混合框跨建筑、黑色立杆及蓝柜。不能把混合框简单记作杆体，也不能按整幅图的主题归类。相对100步，同类IoU≥0.5的对应框有7个，另外12个没有该对应关系；后者包括错类变化或框位置变化，不能统称12个新增错误对象。

光照新丢失8个实例：变压器1、开关柜7。按已有低阈值诊断，4个同类低置信度、3个错类、1个无满足条件的保留预测。开关柜中4个后排目标被前排柜体/圆柱部分遮挡，另外3个较大目标主要呈无面板侧面和顶部。等比缩放到640输入后，开关柜框约38–159像素宽、46–118像素高；还存在366×277像素的变压器漏检。因此“全是小目标”不成立。这8个丢失并非净损失；同时另有命中恢复，光照总匹配数净减少4。

## 实际曝光覆盖

每600次曝光里，新负例只抽18个位姿对，共36图。300步将同一序列重复三次，未增加成员覆盖。

| 新负例子类 | 本轮实际位姿对 | 300步图像曝光 |
| --- | ---: | ---: |
| B1 建筑完整视图 | 3 | 18 |
| B2 建筑边缘截断 | 3 | 18 |
| G1 地面相关 | 3 | 18 |
| G2 地面相关 | 4 | 24 |
| M1 混合结构 | 4 | 24 |
| C1 普通柜体完整视图 | 0 | 0 |
| C2 普通柜体边缘截断 | 0 | 0 |
| P1 杆体 | 1 | 6 |

旧负例另有216次曝光，保持原来24图每图9次。上表的零曝光仅指新负例C1/C2专门子类，不代表模型完全没有见过柜体：已查看的M1训练图中就包含蓝色普通柜体。

对已审核新负例的ROI内容账本加权，地面/阴影42次、建筑36次、混合结构24次、杆体6次，专门标作柜体的ROI图像曝光0次。该统计不是类别实例监督数；空标签负例以全图背景参与训练，混合结构还包含多个可见物体。

本次实际查看了B1/B2/M1各两个已曝光训练图，确认建筑及混合结构并非仅存在于计划文字中。但这6张示例不是对全部训练图的重新视觉审核；完整覆盖交叉表引用既有逐图AI辅助审核。尚未完成全体训练正例的遮挡、面板可见性和尺度分层审计，不能宣布这些正例条件缺失。

## 下一步建议：先冻结一个分层采样对照

建议保留100步、总600曝光、基础216/常规156/桥接120/旧负例72/新负例36不变。只改变新负例18个位姿对的成员选择，使每个设计子类至少得到覆盖：B1=4、B2=4、G1=1、G2=1、M1=4、C1=2、C2=1、P1=1。每对两种光照整体选入，来源隔离不变。

这回答的是“固定预算下由部分地面负例曝光交换到建筑/柜体覆盖是否有益”，不是纯粹增加柜体数据的因果效应。配额是待冻结的下一轮方案，本轮未执行。不得按开发成绩再换成员。

实施时需固定所有共同正样本和旧负例的曝光位置、成员顺序及批次位置，只在指定36个新负例位置替换成员。不能对替换后的整个batch再次按ID排序，否则共同样本位置会改变；应预先冻结最终有效顺序并记录实际顺序。两组从同一权重独立开始，固定端点评估和原有保留门禁；单序列初筛不冒充三seed验收。

同时补做现有训练正例中开关柜的遮挡/侧面/尺度覆盖账本，作为后续正样本组成对照依据，不与这次负例采样对照同时改动。若已有覆盖充足但仍失败，再开展独立的外观增强或优化稳定性对照。只有经账本确认实际结构/视角缺失后才补采，不把当前开发图及其派生图放入训练。
