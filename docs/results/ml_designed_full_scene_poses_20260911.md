# 新位姿设计、筛选及实际核验

本轮完成四类各1个新位姿的原始外观采集、精确重放、全图掩码—框覆盖核验及12个标签的AI辅助审核。四张均可作为下一步有界材质变体的来源候选。没有训练、修改历史标签、恢复旧暂缓来源或部署渲染器。

## 冻结设计

使用既有complex场景和原始外观，仅在独立计划副本保留full_2d + visual-instance + top-level-equipment。设备、几何、光照和传感器参数不变。

固定网格为每15°方位、5/7.5/10/12.5/15米水平距离、3/5/7/9米光心高度，共5280个候选。排除地图外、扩张0.25米障碍物内的光心与载体，排除可解析的已有实际位姿。全图所有可能入镜的四类目标包围盒须在16像素内缩边界内，且这些目标中心射线均不被配置对象包围盒遮挡。38个位姿通过几何预筛；按距离、高度、设备ID、方位和view_id确定性排序，每类固定首个，再开始实际采集。未根据模型成绩或实测结果调整顺序、补换失败图。

16像素仅是本次保守几何预筛参数，不是训练质量准入阈值。包围盒投影及中心射线不能认证真实掩码或完整无遮挡；实际检查仍独立执行。高位相机是离线仿真实验，不构成无人机飞行或安全认证。

## 实核验结果

四张完成canonical采集及同位姿重放，重放均第一次成功；三帧RGB分别与各自新采原图逐像素一致。全部可见映射目标均有完整框，且可见像素落在完整框的1像素容差内。保存实际位姿、同步、实例映射、原始框、RGB、深度、掩码及相关哈希。

逐图查看全图叠框与每个标签独立裁剪：12个标签均有可辨主体。G01的俯视变压器保留三根套管与宽主体；电容器保留封闭主体及基座。G02部分后排柜体有邻物重叠，但仍有较宽主体、面板或顶面，不是极窄残片。G03电抗器完整清晰；G04电抗器被前景变压器遮挡右下部，仍有较宽圆柱曲面及顶面，明确标为部分遮挡。未把中心射线通过描述成完全无遮挡。

这是人工可读的AI辅助审核决定，不是程序自动全量通过；汇总回执绑定12条具体理由和图像/裁剪/标签/重放身份。没有修改历史风险判断。原N/P暂缓组继续暂缓。
