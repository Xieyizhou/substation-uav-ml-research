# 开发集待定框：同帧实例可见性核验

## 判断摘要

本轮完成10个待定框、8张原图的独立来源核验与同帧重放。8次重放均在首次尝试通过技术门禁；原始RGB完全一致，连续3帧稳定，10个目标均有对应实例掩码像素。此前“这些像素究竟属于哪台设备”的缺口已补齐。

逐页查看原图、局部和实例叠图后，10个目标均记为“实例有可见证据，但内容不足”。这是明确的AI辅助内容判断，不是按像素数量自动分档：部分是顶沿窄带，部分是邻柜之间的侧面条带，部分同时处于图缘。不能从实例存在推导出类别易辨、标签适合训练或模型应当可靠识别。

本次不修改历史标签、不排除任何评估目标、不调整阈值、不训练、不读取保护标签、不解封新场景。全部新产物 `training_admitted=false`、`promotable=false`。

## 已证实事实与解释边界

1. **实例并非不存在，也未发现实例映射错配。** 不能以“没有目标”删除这些标签。
2. **框内含前景对象与目标只露局部确实存在。** `full_2d` 框并非可见区域紧致框；这本身不能证明框标错，更不能直接用掩码外接框替换历史标签。
3. **内容不足风险已具名。** 当前类别辨识信息有限，支持将遮挡/图缘片段与清晰目标分层解释，不足以宣布全池标签无问题。
4. 部分目标在图缘结束，但旧记录的 `not_truncated` 不能据此静默改写。完整物体在画外的程度仍需要明确几何定义，当前仅记“图缘片段/截断风险”。
5. 这10个框由本轮漏检审核选出，不是随机抽样。不能把10/10内容不足外推为全开发集风险率，不能用这批损失导向子集估计总体成绩“水分”。

## 对历史成果审计的影响

此前审计的33个现代评估单元和4份早期权重数值复算结论未被本轮改动。本轮新增的是可见性证据，不是重算后更高的成绩。固定全量评估、旧门槛和“未形成通过候选”的结论保持不变。

必须区分两种现象：

- 这些开关柜/变压器局部框的漏检，受到遮挡、图缘和内容不足影响，不能全部视为模型能力不足的干净证据。
- 先前已审核的清晰电抗器仍出现低置信度漏检。当前10框不含该清晰电抗器问题，因此不能用本次遮挡发现解释或抹去它。

## 下一优先方向

已有足够证据制定**独立的开发评估可辨识性分层方案**，不需要继续重放这10框，也不应立即追加训练。

建议先冻结与预测成绩无关的内容分层规则，对原始/光照条件的全部真值进行一致审核，保留清晰、局部遮挡、图缘片段及未知；所有模型使用同一固定分层。继续报告原有全量指标，只增加分层诊断，不把困难目标事后删掉来取得通过。实例映射或标签矛盾另立修订提案，绝不自动改标签。

这样才能区分“全量分数受困难真值结构影响”和“清晰目标真实退化”。随后才针对清晰目标的置信度退化制定受控模型对照。本轮只提出该方案方向，没有实施分层重评、数据修订或训练。

## 完成核验

`completion.json` 记录相关回归实际输出及v2.11固定40文件完整性结果；仅通过后签发。本轮新增审核校验覆盖缺失/重复决定、图像或证据身份过期、实例错配、未对齐或空掩码冒充认证、自动批准和准入越权。复用的重放及评估相关测试同时运行。不声明全仓测试通过。

检测流程完成不代表所有监督风险已消除；它把10个像素归属待定项转为了10条可追溯的内容不足结论。
