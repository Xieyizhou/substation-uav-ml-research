# 整帧暂缓后的曝光补偿可行性

## 判断

三个 seed 均取得经整数与约束复核的计数可行解。保留四张既有暂缓成员，并追加 T027 三个同源成员及 T036 一张，共八张在假设计数方案中为零；历史数据及实际训练记录没有变动。

复核既有两轮全标签审核的成员图像／标签、逐框坐标、局部证据哈希及决定覆盖，结合原冻结增曝白名单，排除新增风险后得到 29 张增曝候选。这里只复用明确的逐框内容决定，不把整帧筛查当批准；也不代表已认证所有候选不存在未标出的实例。

约束保持：三个 seed 各自的子集预算和四类完整标签实例曝光总量不变；负例成员计数固定；未知／非白名单成员不增曝；旧风险谱系总量不增；原先零曝光成员不恢复。未生成顺序，故没有改动任何负例位置；后续顺序构造仍须验证位置严格不变。

本次目标只求可行，没有最小改动或均衡优化。表中暴露了任意可行解可能高度集中、扰动大量曝光的风险；不能直接拿这些计数训练，也不能宣称补偿有效。它们是存在性证据，不是建议配比。

## 下一步建议

在相同冻结候选和约束下，先最小化单图最大增量，再在该最优上限内最小化总改动；保留三个 seed，不按模型成绩选配比。报告最大单图曝光、谱系集中度与每 50 步窗口影响。若仍集中，报告取舍，不自动放宽来源或审核门禁。

随后只核验最终增曝成员的来源和全图完整性，尤其检查是否还有旧渲染器导致的未标实例；不能仅凭已有标签逐框内容合格而放行。技术／质量通过后才考虑独立顺序冻结和加载器预检。本轮不生成修订训练池、不改标签、不训练、不采集，也不安装生产渲染器。

解释边界：说明删除风险整帧后的计数恢复在当前约束下可实现，不证明训练能力能够恢复，更不证明风险图是历史退化的唯一原因。
