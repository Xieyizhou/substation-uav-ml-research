# 材质保留与覆盖对照：开发评估和错误审核

## 结论

六个独立训练单元均完成450步；固定开发评估、低阈值诊断及12个同源位姿的七条件诊断完成。T、A两组均未通过完整门禁，不选择候选。所有产物保持 training_admitted=false、promotable=false；没有修改标签、阈值或解封新场景。

结果支持“模型对训练中的外观分配有响应，同时存在能力取舍”，不支持“只靠颜色”或“已经转为结构识别”的强结论。

## 同源拟合与条件迁移核对

12个位姿×七条件是已查看的同源诊断，不是独立泛化测试。三seed不增加独立位姿数。下列命中均以每seed12个计划目标计算：

- 历史纯灰G的暖色命中均值16.67%，T恢复到58.33%，A为50.00%；冷色由G的47.22%恢复到T/A的61.11%。
- 目标主体灰色命中由G的77.78%变为T的61.11%、A的55.56%；全设备主体灰色由G的77.78%变为T/A的63.89%。
- 原始控制条件T/A均为100%，但这不能替代固定开发集能力保留。
- 仅统计各模型实际曝光的灰色成员：T三个seed依次命中5/7、4/7、4/7；A为3/7、4/7、5/7。已有曝光也未达到全部命中，但这些数字本身不证明所有漏检标签都有充分可辨内容，更不能单独归因为步数不足。

这是颜色覆盖保留与灰色效果之间的取舍证据。零曝光ID不等于未见像素；同源变体与像素别名保留共同分组。

## 错误审核

完成92张证据卡的显式AI辅助审核：15个无目标误检框（8张图、7个来源位姿）及84个唯一条件内真值目标，共99条决定。四类比较的201个损失事件映射到这84个目标；2880条得益、损失及持续状态全部保留，重复seed或比较不增加独立样本数。

无目标误检覆盖面板、块体立面和混合结构，不按整帧主题推断来源资产身份。
漏检目标观察包括11个主体清楚、10个背侧/有限内容、16个主体遮挡、23个局部遮挡、24个图缘截断。未删去任何难例；没有可靠实例掩码，不认证像素级可见性。没有未填写或unknown决定不等于数据质量全部获批。

具体证据包括E73/E86/E91的清楚圆柱，以及E88的灰色面板柜体，说明不能把全部漏检归结为不可见。全部审核与预测、来源和证据哈希绑定。

## 一个优先方向

优先设计“固定成员与总曝光的单变量曝光顺序/拟合对照”，而不是继续临时加灰色比例或宣布需要更大模型。先从实际曝光灰色成员的漏检中核实完整标签和可辨内容，冻结有效样本及其出现位置；再明确选择一个顺序因素，保持成员多重集、总步数、亮度及其余配置不变，并检查是否与历史顺序对照重复。若监督风险未解决，先阻断该模型对照。

理由：保留颜色能恢复暖冷条件，但灰色下降；扩大灰色覆盖并未在同源七条件上形成一致额外收益，且实际曝光成员仍有错误。当前更需要区分“样本未学稳”与“条件迁移取舍”，没有证据支持直接把唯一原因归为颜色或结构网络不足。本轮不启动后续训练。
