## 采样冻结

整数优化采用已冻结的三级目标：最小化四类全图标签实例曝光极差；继而最小化与 Q 的成员曝光次数 L1 差；继而确定性 seed 排序打破同优解。仅使用训练标签，没有按开发集成绩选取成员。求解依赖在 uv 隔离环境运行，未修改原训练环境。

## 启动前修复

首次预检因整批排序改变负例绝对位置而拒绝，训练未启动。修复为仅在每批正样本槽位内排序，负例槽位固定；新增跨成员 ID 前缀的对抗测试通过。这也意味着相对 Q 的正样本批次组成和数值归约顺序会改变，不作纯类别曝光的因果归因。

新增 2 项采样测试通过，原相关 23 项回归通过。独立入口 `check_instance_exposure_balance.py` 逐项核对标签计数、成员上下限、子集配额、负例绝对位置、100/300 前缀和重复序列、冻结曝光及基线。实际通过状态以 `preflight.json` 为准。

## 训练与判断

I-100 与 I-300 各 seed 7、17、27，共六个独立单元；使用原 `.venv`、v2.11 初始化、CPU、640、batch 6、AdamW、恒定学习率 0.001、无预热和关闭增强。全部只使用预定终点，全部 seed 完成才判断家族。

复用原正式及低阈值评估；保留全部数值门槛及相对同预算 R、历史 A 的 5 个百分点能力保留容差。候选顺序 I-100 后 I-300，不挑 seed。不完整尝试独立保留，每单元最多三次；运行锁防重复启动。

运行入口：`scripts/vision/run_instance_exposure_balance.py`。完整结果以新目录 `completion.json` 为准；没有该回执就不能声明训练实验完成或模型通过。所有产物 `training_admitted=false`、`promotable=false`。
