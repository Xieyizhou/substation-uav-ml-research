# 旧外观/背景实验勘误（2026-09-07）

`appearance-background-v1` 的世界生成脚本曾在一棵 XML 树上修改 bounding-box 相机 `box_type`，随后重新解析并保存另一棵树，导致实际世界仍可能使用 `visible_2d`，而计划声明为 `full_2d`。因此旧外观/背景结果应标记为：**实际标注模式与声明不一致，不能用于严格因素归因**。

旧文件保持原样并仍可读取，不追写身份或覆盖历史结果。旧结果只可作为发现问题的历史开发诊断，不可与新的 `paired-visual-factors-v1` 合并为同一严格配对实验，也不可作为训练准入、模型晋升或跨站点结论。

修复后的脚本在同一 XML 树上修改并保存 `box_type`，保存后重新读取确认；canonical 采集入口还会在 Gazebo 启动前独立核对计划声明、实际世界模式、实例映射、世界哈希与相机合法性。哈希一致不再被视作配置语义正确的替代证据。
