# 新来源四类小批探测：完整标签与可辨内容双门禁

本轮从上一批未使用的21个登记位姿组中，排除全部原12组、已有暂缓组及可解析的已曝光实际位姿，按固定类别、距离、设备ID、方位和view_id顺序，各取一个来源，冻结P01—P04后再重放。没有依据模型成绩、审核结果或失败情况临时换图。

这些是保存来源的同帧重放，其中部分已经改过材质，不能称为新实验的原始外观V组。共享complex布局与资产；未解析历史位姿仍限制来源隔离结论。

四帧均第一次技术尝试完成。RGB与各自原帧完全一致；四帧共22个既有标签均有新AI辅助审核理由。没有生成新的暖／冷变体，没有训练。

## 重要判断

本批没有合格来源。证据支持“复杂场景中非计划设备的图缘截断、遮挡及完整框输出缺口，是当前材料建立的主要阻断项”。这不证明模型材质敏感的唯一原因，也不证明其余17个未测试位姿均不合格。

继续给已有图换颜色不会解决这些问题。下一优先步骤是独立冻结新的相机来源设计：保留四类及距离/方位覆盖，先以全图设备的投影边界和遮挡作几何预筛，再对固定小批运行真实RGB、实例掩码和完整框核验。几何预筛只能排除明显风险，不能替代真实可见性认证；不移动设备、不改旧标签，不从保护测试取来源。不按模型成绩选择位姿；失败组保留，不静默补成成功数。

已累积的暂缓谱系在新回执中明确列出，后续候选导出必须消费。历史文件、旧审核和失败回执不改写。此前旧审核依赖链问题仍保留，不把本轮局部取证通过描述为历史准入链通过。
