# 来源保留材质对照：补充、核验与训练启动

## 当前结论

已完成获授权的一个B布局变压器位姿、四张候选补充，启动两家族各seed 7/17/27的六单元训练。首单元E-7已有检查点，核查时AdamW状态为50个优化步，学习率0.0005，进程存活并在计算。不是训练完成或模型验收通过。

## 数据与质量

新增位姿保持B布局、资产、几何、光照和材质参数，采用独立目录，不修改旧64张、标签或暂缓决定。四张采集成功，全部第1次同帧重放通过，配对框差为0。逐帧查看了变压器及非计划开关柜：主体、顶部三根套管、柜体面板及基座可辨。俯视来源侧面覆盖有限，不能宣称补齐所有几何多样性。

原64张中的4组内容风险继续暂缓。训练选择两布局各四个计划类别来源，共8个位姿组、32张候选，52个标签审核决定明确标为AI辅助审核。旧组变体的像素级可见性没有借用原始帧认证；新补充的四种条件分别获得精确重放证据。没有宣称全部68张都合格或都进入曝光序列。

文件及原尺寸RGB排除检查未见与当前池、固定开发图及保护指纹的精确重合；未读取保护标签。两布局复用已有资产，近似变体按同源组登记，不宣称独立资产或跨站点泛化。

## 冻结实验

E为新来源原始外观对照，M为相同来源保留原始后的材质组。每个seed共2700次曝光、450步；原T中2184次原始正例及486次负例的成员、位置和亮度参数保留，仅替换30个原材质位置。

- 每布局电抗器、电容器组、开关柜来源各4次曝光，变压器来源3次，共30次。
- E的30次全为原始。M每来源保留一次原始，共8次原始、22次材质；材质次序按版本化哈希确定。
- E/M的来源、完整类别实例曝光及逐位置完整标签相同，不按模型分数选来源或顺序。
- CPU、640、batch/nbs=6、AdamW、恒定LR0.0005、无预热、仅冻结亮度增强，从v2.11独立初始化，只保留预定终点last.pt用于评估。

相对历史T，每个新家族每seed的电抗器、开关柜、变压器实例曝光分别减少8、8、16次，电容器组不变。历史比较不是纯材质因果对照；E/M才是相同新来源预算下的主要比较。

## 门禁与运行

六个真实加载器分别遍历2700次，共16200次/2700批，完整标签、成员、亮度张量检查通过；未创建优化器、反向传播或训练验证。23项本轮及canonical针对性测试、22项复用运行与评估回归通过；v2.11固定40文件完整性通过，不声明全仓测试通过。

独立启动入口为 `scripts/vision/run_closed_source_control.py --train`。默认命令不训练。每个worker重新验证质量证据、软件环境、就绪回执与输入；技术尝试有界，失败保留记录并清理本次子进程。运行顺序E-7、E-17、E-27、M-7、M-17、M-27；不是六个CPU训练并行运行。

本次启动器只串联训练，不自动执行开发评估。训练后的推理继续使用已冻结双阈值0.37/0.001、CPU640、同类NMS0.7、max_det300、同类匹配IoU0.5及原门槛。训练拟合不能代替开发评估；不部署、不晋升、不解封新场景。

全部产物training_admitted=false、promotable=false。仍需完成六单元训练、统一评估和错误审核，才能判断原始能力是否保留及材质收益是否跨seed复现。
