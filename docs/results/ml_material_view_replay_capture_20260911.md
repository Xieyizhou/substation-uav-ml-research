# 修复重放与材质候选采集结果

已推进到真实候选图采集及逐图审核，不只是建立世界草案。本轮不训练、不改历史标签、不部署渲染器、不解除原暂缓成员。

## 技术修复及重放

保留v1三次时间戳解析失败，在用户明确授权后建立独立v2有界复验。使用已测试的解析函数接受protobuf整数字符串，仍拒绝缺失秒数、非有限或非整数时间。程序错误会立即停下，不再连续消耗同类错误的全部次数。

N04、N02各第一次重放通过：连续三帧RGB与原图完全一致，完整框坐标差为0，最大同步差均为32毫秒，实例掩码及位姿门禁通过。所有启动进程已清理。

N02全图掩码仅见目标标签57（transformer_se）、178（capacitor_east），与原始完整框一致，未发现有可见掩码但没有框的映射目标。蓝块不属于四类已映射目标的像素，不能称四类目标漏标；背景标签0不提供普通柜体的独立资产ID，因此不把它进一步认证为cabinet_center。原有RGB观察与本次掩码证据分别保留，不修改旧审核。

## 历史哈希处理及边界

变化来自已知旧依赖问题：metrics-v2绑定旧review.json，而消费新版review-v2.json。当前审核脚本哈希与新版review-v2绑定的091d3f…一致；旧版绑定466bbb…，已经失效。material-control-feasibility-v1/initial-gate.json曾明确记录该问题。

本轮没有“刷新旧哈希”，也没有恢复未知历史脚本。旧链不能重新认证，历史旧分层结果不得作为候选准入依据。新重放直接校验保存图像、完整原始框、世界、位姿、映射与运行输出，不消费旧分层决定作批准。这允许取证和采集开发候选，**不代表完整历史训练准入链已经修复**。

## 已采集与审核

基于N04建立原始／warm／cool三张真实图，均第一次采集通过。每张有三个完整真值，掩码与来源认证重放逐字节相同，框成员一致且差异≤1像素。改变RGB属于预定材质因素；新图不是原帧RGB完全一致认证。

原始组所有设备恢复原始材质；warm/cool相对该原始组只改变计划目标entry_switchgear主体的ambient/diffuse，面板、基座和其他设备材质保持不变。共享一个原位姿及复杂布局/资产，三张图不是三个独立样本。

逐张查看全图叠框及各自三个目标裁剪，记录9条AI辅助审核理由：计划柜体三种颜色下完整可辨，后排柜体部分遮挡但主体及面板可辨；右图缘非计划变压器仅见宽侧面和基座、无套管，严重截断及类别特征有限的问题仍在。其三条审核明确为监督质量待核验，不以掩码可见代替质量通过。因此三张均为候选，不导出正式训练成员。

## 当前判断与下一优先步骤

重放能力和时间戳修复已通过现场验证，能够建立预期材质变化且保持实例几何的候选图。当前交付3张图、1个位姿组及9条审核，不是规划中的36张完整材料集；仍缺其他类和位姿。

下一步优先核验右缘非计划变压器的监督适用性及其他来源的全图风险，形成独立、明确的候选准入记录；不能只因计划目标清晰就放行整图。N05及其余来源未在本轮扩大采集。历史旧链的失效范围继续独立保留，后续曝光冻结必须使用重新核实的数据身份与排除清单，不能沿用旧分层批准。
