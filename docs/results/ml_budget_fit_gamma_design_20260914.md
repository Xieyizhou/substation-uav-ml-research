# 电抗器拟合核对与下一改动方向

## 已完成分析

本轮B450/B900六份权重对333张冻结池成员完成双阈值推理，CPU双进程、各4线程；保留全部类别完整标签。仅实际曝光成员计入训练拟合，未曝光结果仍保存，不算泛化测试。

电抗器实际曝光真值命中（seed7/17/27）：35→39、38→40、34→39，各40个实例。合计107/120→118/120，11个得益、没有新增损失。材质电抗器9/18→18/18；原始98/102→100/102。重复seed不是独立来源。

与此同时，开发原始及光照电抗器召回均下降6.67个百分点。证据不支持“电抗器在训练成员上普遍遗忘”，而支持训练拟合改善未充分延续至开发条件。不能据此确定是材质、光照、遮挡、视角或资产差异的唯一原因。其他类别仍有局部训练损失，尤其seed27的开关柜；全部得失留存在paired-analysis.json，不能只报电抗器收益。

## 单一优先改动

采用有界Gamma明暗扰动对照，保留已验证B900三个seed为参考，新增G900 seed7/17/27，从v2.11独立初始化，仍900步、batch/nbs6、CPU640、AdamW、恒定LR0.0005。全部5400成员、完整标签、负例位置、冻结亮度顺序不变，只增加Gamma因素。

在现有亮度之后，对HSV的V通道应用round(255*(V/255)^gamma)。每900批固定450批gamma=1（严格恒等，无HSV往返）、225批0.8、225批1.2；每50步保留25个恒等批次，其余12/13交替分配，版本化SHA-256冻结顺序。一个batch六张使用相同Gamma，负例也受该新增因素影响，不声称负例像素保持不变。

这不是新光照渲染、独立来源或结构多样性补充；量化可能合并色阶，先检查增强预览及真实张量。历史从头降低LR和宽范围多尺度实验没有证明该因素有效；本轮也不同时改变LR、尺度、模型结构或曝光配比。

Gamma=.8/1.2是预先固定的小范围试验参数，不是经过验证的最优参数。不以接近门槛为由调阈值、挑seed或追加实验。既有待定开发目标不删除，旧标签与质量决定不重写。training_admitted=false、promotable=false，封存新场景不打开。
