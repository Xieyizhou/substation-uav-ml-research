# 开关柜训练条件审核：覆盖存在，但低对比面板监督集中且有待核验项

## 重要判断

已逐项查看111张已有训练图的293个开关柜标签框，并为33项补查全图。266项条件判断可记录，27项仍为unknown/待定。本阶段完成的是“全部框已检查并保留待定项”，不是“全部条件已确认通过”。没有重新训练、删除、改标或晋升。

结论分三部分：

1. 侧面和遮挡样本并不缺席，不能再笼统声称模型没有见过这些条件。
2. 明确可见的低对比面板监督只有10个标签事件，来自4张图、4个谱系，当前每600次训练图像曝光仅产生20次此类开关柜实例曝光。已有覆盖不等于覆盖充分，这一条件的有效支持很集中。
3. 存在图像边缘/严重遮挡条件下无法可靠判断的标签区域。应先核验具体实例可见性，不能为继续训练把unknown自动变成通过。

这些证据尚不能证明标签错误造成全部模型退化，也不能单凭小计认定增加这些图的重复次数就能解决问题。

## 范围和方法

沿用上一轮尺寸普查身份：基础池90框、常规104框、桥接99框；合计293个“图像—标签行”事件，来自111张图、91个谱系。重复曝光、同源变体和同一图内多个框不算新增独立样本或资产。

逐框查看原图裁剪，保留上下文及红色标签边界；原图放大不增加真实细节。对33个初步不确定项补查完整图像后，6项条件能够明确，27项保持待定。全部判断统一标记AI辅助，记录时间、源图/标签/证据哈希及理由。

“未见面板”只表示当前可见平面或顶部未显露面板，不推断背面是否有面板，也不等于“面板对比度低”。遮挡仅作无明显/部分/较重/未知的视觉分档，不报告未经测量的遮挡百分比。框接触图像边界另外按原图1像素记录，不等同精确截断率。

## 面板条件与实际监督曝光

| 条件 | 标签事件数 | 每600次图像曝光中的实例曝光 |
| --- | ---: | ---: |
| 当前可见面无可辨识面板 | 204 | 619 |
| 面板可见且对比清楚 | 52 | 165 |
| 面板可见但对比较弱 | 10 | 20 |
| 无法确认面板条件 | 27 | 79 |
| 合计 | 293 | 883 |

10个低对比事件全部来自桥接正样本，只有4张图、4个谱系；20次实例曝光占883次开关柜监督约2.27%。不能把619次“面板未显露”当作低对比面板覆盖，也不能把79次未知监督计入已确认覆盖。

基础池/常规/桥接的明确面板事件分别为10/22/20，低对比事件为0/0/10。本轮没有用开发成绩选择这些分档，也没有因此改动采样。

## 遮挡条件

无明显前景遮挡105框、部分遮挡104框、较重遮挡78框、遮挡关系未知6框。较重遮挡与面板未知不是同一集合：有的目标只显露普通平面但仍可记录“当前面板未见”，有的无法可靠归属可见结构则保留unknown。

这排除了“训练中完全没有遮挡/侧面”的简单解释，但没有证明遮挡比例、视角、材质和类别组合已经足够多样，也没有认证各框的像素可辨识性。

## 待核验和下一优先级

27项来自23张图，清单在review.json。最优先复核三项：

- T049：基础图`expanded-stratified-v1/images/047.png`，标签第2行；右边缘框主要呈地面/边界细条。
- T054：基础图`expanded-stratified-v1/images/051.png`，标签第2行；左边缘框主要呈地面/边界。
- T148：常规图`visual-augmentation-training-v2/pool/images/175.png`，标签第5行；右边缘框主要呈地面。

这里的行号为1起算；机器记录label_line_index为0起算。需要回查来源回执、实例身份、实际标注模式与裁剪投影，判断是真实可见片段、离屏投影框、遮挡目标框还是映射/导出异常。仅凭缩略图不能擅自删除或改标；更不能把包含其他目标的整幅图改为空标签。

另外一些框位于前景变压器顶部/侧面区域，后方开关柜几乎被遮住。当前无法可靠判断其面板，仍保留待定；不因标签类别存在就宣布可见性通过。

历史训练成员、旧回执与模型全部保持原样。本轮没有宣布原训练池整体作废，但也没有给新的训练实验开出“所有条件已确认”的结论。

## 下一步推进顺序

先核验上述3个高优先级边缘框及同类待定项的来源/实例链，明确处理规则并记录勘误或维持原标签的理由。需要修改数据时建立新版本，不覆盖历史文件。

随后冻结一个基于真实条件的正样本对照，关注低对比面板与可辨识目标，而不是再随机增加灰度增强或负例比例。现有4张低对比图重复曝光不会增加独立视角；若谱系/条件核对后确认覆盖不足，才申请独立位姿的定向补采。不得将已查看开发图及其派生图放入训练。

目前不再启动新的模型或参数试探。此前灰度、分层负例和延长训练的未达标结果保留，不根据本次审核重写历史成绩。
