# 尺度端点核对与判断

## 判断

不选择小尺度端或大尺度端作为下一代模型，也不继续立即搜索尺度参数。小尺度端的低误检是有效开发线索，但不能抵消材质和光照类别损失；大尺度端没有跨seed稳定解决材质问题。下一优先方向是使用本轮已有权重做相关训练成员拟合诊断，先区分已曝光样本未学稳与开发条件迁移受限，不追加训练。

## 核对范围

六份训练完成回执、实际曝光及张量身份有效。逐实例重新计算并核对1440次模型–真值得失（两组×三seed×240真值），与评估汇总一致；逐框匹配至已纠正设备ID，不借用计划目标ID。重复seed不是新增独立样本。

本轮两组全部9个无目标误检框已查看全图叠框和放大图，保存明确AI辅助审核。新增正样本漏检本次做完整身份／数值核对，未宣称完成全部新增漏检的逐图视觉认证；既有邻柜实例归属待定继续保留，不过滤全量门禁。

### 小尺度端：有低误检收益，但不是材质方案

无目标误检帧由固定组1、2、6降为1、0、0（每seed48图），三个seed均未变差，两个改善。不过唯一剩余误检是青色柜状块体，置信度0.902，并非只剩接近阈值的噪声。

原始全图召回seed7由76.67%降到68.33%，seed17/27则提高，平均值掩盖一个seed的退化。材质全图召回为8.33%、10%、20%，对应固定组15%、26.67%、18.33%；只有一个seed小幅提高。

光照变压器召回三个seed均下降：83.33%→77.78%、72.22%→33.33%、72.22%→61.11%，均值下降18.52个百分点。即使光照计划命中均值保持58.33%，也不能称光照能力保留。

### 大尺度端：计划命中提高，没有带动整体稳定恢复

光照计划命中均值63.89%高于固定58.33%，但光照全图召回仍下降1.67个百分点。材质全图匹配计数由9、16、11变成17、9、13（每seed60真值）；seed17损失明显，不能称跨seed稳定改善。

两端材质电抗器均只有2/15次匹配，低于固定4/15；这是五个图内真值×三个seed的重复测量，不是十五个独立实例或场景。大尺度原始条件电抗器相对当前固定组相同，但相对历史A仍未满足保留要求。

大尺度8个无目标误检全部主要涉及灰色块体的侧面／面板／基座或它们与前景杆、青块的混合结构；不支持把下一步负例方向简单设成杆体。

## 能确认与不能确认

能确认：两个单端策略都没有达到材质门槛和完整能力保留门禁；小尺度条件下有稳定的光照变压器损失。不能确认：上一轮混合尺度退化全部由320导致、960一定安全、或单纯延长训练即可解决。端点对照把非640批次全部改为同一端点，单端剂量是上一轮该端的两倍，因此不能线性拆分混合策略的因果贡献。计算量也不同，960为640插值而非新增细节。

## 下一步唯一优先方向

对固定、小尺度、大尺度全部三seed已有终点权重，在已审核且实际曝光的相关训练成员上做640输入的正式／低阈值拟合核对。重点是灰色变压器、电抗器和相应光照条件；按各模型实际曝光区分共同已见成员，先确认是否有合格的对应光照训练成员，不把人工合成暗图当历史训练成员。

若训练侧已学稳而开发侧失败，再冻结条件／来源多样性对照；若训练侧也不稳，再设计单变量采样或优化对照。当前不直接重训、调阈值、挑seed或把小尺度权重继续微调；两组均不晋升。这样下一步可用已有权重回答关键分叉，避免继续盲搜尺度。

本次为有边界的核对结论，不是全量新增漏检视觉审核完成；所有产物training_admitted=false、promotable=false。针对性回归及固定40文件结果绑定于`scale-endpoint-control-v1/diagnosis-v1/completion.json`。
