# 材质—视角候选来源建立与首轮审核

本轮完成来源候选建立及显式 AI 辅助视觉审核，结论是 `source_review_complete_candidate_build_blocked`。没有采集新训练图、生成完整36张变体集或启动训练；没有修改历史标签或恢复暂缓成员。全部新产物保持 `training_admitted=false`、`promotable=false`。

## 已完成与证据范围

从已有240张候选来源中，153张通过本次保存文件、相机合法性和实例映射的事后核对，合并为33个登记位姿组。其余87张：48张不是定向正例、33张属于已曝光成员或登记位姿、6张属于既有暂缓成员或谱系。这不是对历史采集门禁的追认，也不是153张通过质量审核。

按四类设备、距离排序区间及确定性来源顺序，固定选出12个位姿来源，逐张查看全图叠框及全部54个真值的独立裁剪。没有根据模型成绩或审核结果更换位姿。设备ID由每个框自己的实例映射解析，不使用计划目标代替。

显式观察记录见 `material-view-candidates-v1/visual-observations-v1.json`，绑定固定审核清单哈希。导入器校验完整覆盖、重复、版本及证据依赖，仅汇总已有决定，不生成通过决定。

## 校正与限制

保存世界中存在 `cabinet_center` 蓝色普通柜体，其主体 diffuse 为 `0.02 0.32 0.43 1`，不在四类目标实例映射内。这支持“未框蓝块可能是非目标资产”的解释，**尚不证明每个蓝块对应它，也不能认定这些画面已经漏标**。

11张来源的 `material_id` 为 `mat_cool_gray`，但实际世界并非所有类别统一灰色：柜体主体/面板为 `0.43 0.31 0.23 1`，电容器主体为 `0.28 0.38 0.32 1`，变压器及电抗器主体为 `0.35 0.37 0.40 1`。这只是历史材质族名称，不是统一灰色语义。只有N08来源登记为原始材质；其余不能直接作为新V组的原始外观对照。

全部来源仍共享complex布局及设备资产。33个登记位姿组不等于33个独立场景；本次排除了可解析的实际已曝光位姿，但历史未解析位姿仍限制隔离结论。没有读取保护标签或解封新场景。

## 下一优先方向及停止点

优先做这批来源的**定向实例归属和内容风险核验**：保留14个待定框及4张蓝块疑点对应的原帧证据，先核实资产对应，再选择少量代表帧验证同帧重放能力。只有RGB完全一致、映射唯一、位姿/同步及框漂移门禁合格时，掩码才可认证原帧；否则保持具名缺口。不通过时应设计独立来源替换/处理方案，不修改历史标签。

在上述风险解决之前，不扩大生成36张变体、不冻结曝光替换、不训练。后续还需从可验证原始世界建立V/VM三种外观、检查只改变允许字段、完成每张变体全标签审核及精确曝光可行性核验。当前证据不足以称候选数据已建立完毕，更不能宣称模型改善。

针对性测试及v2.11固定40文件核验另见本目录数据完成回执和验证回执；不声明全仓测试通过。初次测试调用误用了不存在的测试模块名，保留为执行错误，纠正命令后重新核验，不记成代码回归失败。
