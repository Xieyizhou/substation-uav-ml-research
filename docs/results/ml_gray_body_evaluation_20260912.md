# 灰色主体替换对照：评估与逐框审核

## 判断

本轮三个 seed 的正式／低阈值开发推理和错误审核完成，但模型家族未通过门禁，不选择候选、不晋升。仅替换30次曝光没有带来稳定的材质收益；不能据此宣称灰色样本无效，更不能确定唯一根因。

比较对象为历史 VM-7/17/27 与新 G-7/17/27。每单元从 v2.11 独立初始化，450步、2700次曝光；30次同源 warm/cool 替换为灰色目标主体，其余位置、完整类别实例曝光、负例位置及亮度系数不变。材质成员及成员与增强组合发生变化，属于策略对照，不是纯颜色因果实验。

## 错误审核

逐一查看43张审核卡的全图与独立裁剪，形成44条AI辅助逐框决定：6个无目标误检框（5张唯一图像、4个来源位姿）及38个独立的“条件—真值框”新增漏检目标。38个目标对应41次seed损失事件，三seed全部720次真值转移均保留，含54次得益、336次持续命中、289次持续漏检；这些不是720个独立实例或场景。

- 误检全部来自seed17：3框覆盖灰色块体、杆体和青色柜状物的混合区域，1框以灰色立面为主，2框覆盖同一灰色面板结构且分别预测为电容器组和电抗器。视觉外形不是资产身份认证。
- 新增漏检操作性分类：32次同类低置信度、6次错类、1次定位不足、2次未发现合格保留预测。最后一类受NMS和max_det约束，不能解释为网络没产生候选。
- E20/E31的原始电抗器、E28/E29的光照开关柜主体清楚，说明新增错误不全是遮挡／截断所致。E07/E08/E22等后排柜体仅露顶面窄带；E10/E41/E43圆柱下部受前景设备遮挡；E17/E34只展示电容器组背／侧面。这些局限保留在完整指标中，不删标签、不自动ignore。
- seed7有19得益／5损失，seed17有22／9，seed27有13／27，存在明显波动和取舍。

此次为RGB内容的AI辅助审核，不认证实例掩码级可见性，也不重新批准训练标签。没有自动生成全量通过意见；所有决定绑定原图、真值或预测、来源和审核页哈希。内容有限与遮挡并不等于数据身份冲突。

## 证据完整性与边界

三份训练终点和实际曝光重新核验；六套推理（3模型×2阈值，共576次图像推理）完成。计划命中与全图匹配冲突为0。v2.11固定40文件核验通过。针对性回归结果及脚本身份绑定在evaluation/completion.json；不声明全仓测试通过。

没有训练、补采、改阈值、修改历史标签或访问封存测试。12组开发位姿共享既有布局和资产，结论仅是本开发场景的方向性证据；training_admitted=false、promotable=false。

## 唯一优先方向

先做本轮已有权重对12张实际曝光灰色主体图的训练拟合核对，并在现有同源七条件诊断图上比较，不追加训练。重点区分：灰色训练目标本身未学稳，还是训练目标已学会但未迁移到“全场灰色＋面板变化”的开发条件。固定三seed、原推理协议和实例匹配，不挑seed。

若训练侧仍错误，再设计单变量优化／采样对照；若训练侧正确而同源其他条件失败，再设计条件范围迁移对照。当前证据不足以直接决定加曝光、改结构或全场重采，也不以本轮未通过为由无限追加实验。本阶段在完成评估与审核处停止。
