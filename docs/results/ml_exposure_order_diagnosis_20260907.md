# 曝光顺序对照：完成报告

## 重要判断

固定相同成员、每张图曝光次数和训练seed后，仅改变曝光排列就足以改变终点模型与开发结果。尤其W只在每个batch内部重排，实际batch成员及批次先后都未改变，仍产生超过预定口径的差异。下一步应优先核查训练链路的batch置换一致性，不能继续把变化单独归因于数据覆盖或训练seed。

本轮不选候选，不继续搜索有利顺序。G的误检改善伴随原始召回下降，不构成已达标的模型改进。

## 冻结设计与实际执行

参考F为上轮已核验的F-100-7终点；其另外两个训练seed已证明在相同输入下结果完全一致，因此本次复用一份参考，不把它们当作三个新独立参考样本。

| 组 | 唯一预定变换 | 保持不变 |
| --- | --- | --- |
| W | 每个batch内的6张图重新排列 | 每个batch的成员、每张图次数、100个batch的先后 |
| B | 100个完整batch重新排列 | 每个batch的成员和内部顺序、每张图次数 |
| G | 全部600次曝光重新排列并分组 | 成员多重集，即每张图及其次数 |

三种变换均由预先固定字符串随机源生成，未参考成绩。G同时改变分组和先后，不能进一步隔离这两项的各自贡献；B会改变成员出现的训练时点及跨epoch分布。

统一seed7、v2.11初始化、CPU/640/batch6/nbs6/AdamW/lr0.001，无预热、恒定学习率、增强关闭，100优化步，使用预定last.pt。每组分别重新训练，共300优化步、1800次图像曝光。

每单元基础216、常规156、桥接120、旧负例72、新负例36；222张独特图像。全图监督曝光仍为变压器713、开关柜883、电容器组200、电抗器179。运行回执确认三组与F成员多重集完全一致，W/B的额外batch约束也通过；除输出路径外训练参数与F一致。

独立产物目录：hard-negative-coverage-v1/exposure-order-diagnosis-v1。历史脚本、训练、评估、审核未被修改。

差异检查为操作性口径：相对F的绝对FPR变化达到2/48、原始/光照计划命中变化达到2/12，或原始/光照全图/逐类召回变化达到0.05。不是统计显著性检验，不代表每一项指标都显著变化。B的FPR变化本身未达到此口径，其明显差异主要在召回。

各组参数哈希及逐图预测均不等于F。state_dict最大绝对差分别为W 9.21875、B 27.15625、G 25.859375；最大差值位于BatchNorm运行方差缓冲区，并不是普通权重差值。仅凭终点缓冲区差异，不能认定BatchNorm就是起因；它也可能是不同训练轨迹的结果。

## 当前能判断什么

1. 不是“新增样本覆盖不同”：本轮每张图出现次数一致，W甚至每个batch的成员都一致。
2. 在当前链路中，batch内置换不能被当作对训练结果无影响的操作。理论上的样本对称性不能替代实际运行验证。
3. 但目前尚未定位第一处分歧：可能涉及输入/标签索引、损失计算顺序、浮点归约、状态更新以及微小差异的后续放大。不能据此直接声称实现存在标签错位，也不能直接认定只是浮点误差。
4. G单次较低FPR不能证明该重排更优；它仍超过10%均值门槛，且有召回取舍。本轮单seed诊断不满足三seed候选判断条件，没有模型晋升。

## 下一步建议

先做单batch置换一致性审计，而不是追加完整训练：从同一初始权重复制状态，取同一批图像/标签及其W排列，核对预处理张量、标签batch索引、逆置换后的前向输出、损失分项、梯度及一次优化后的参数/状态。明确记录误差尺度，并检查eval/train两种模式和必要的状态缓冲区。

如果第一步就出现非数值级的身份或计算差异，再诊断具体实现；如果初始差异很小，则沿固定W/F序列记录首次扩大位置，研究短预算优化中的误差放大。只有完成这项审计后，再决定修复、优化过程对照或数据组成实验。本报告未执行该下一项审计，也未改动训练实现。
