# 分层负例覆盖100步对照

## 结论与决定

训练、固定开发评估及低阈值诊断已完成。覆盖八个子类后，无目标误检减少3帧，光照召回改善，但材质计划命中减半、原始电抗器召回下降20个百分点。**本轮不采用该权重，不晋升，不继续临时改配比。**

这说明该条固定序列上的负例覆盖替换带来了明显取舍，不能作为解决方案。不能把结果解释为柜体或建筑某个单独子类的因果效应，也不能推断所有分层采样均无效。与此前100/300步对照合看，单纯延长训练、单纯补齐负例子类均未取得满足约束的结果；检测问题的全部病因仍未被唯一确定。

## 冻结与实际执行

参考为已验证CF-100-7；新增S-100-7独立从v2.11初始化。CPU、640、batch/nbs 6、AdamW、lr 0.001恒定、无预热、原增强关闭、seed 7，固定100步last.pt终点评估。没有按成绩挑checkpoint。

600次曝光配额保持基础216、常规156、桥接120、旧负例72、新负例36。共同564次曝光的成员和位置完全一致；只在36个预定新负例位置替换成员，没有再次排序batch。实际训练记录与冻结序列逐项一致，类别实例曝光不变。

新负例18个位姿对、36张图，来自18个相关性分组，仍属于同一开发场景，不代表18个独立场景。按B1/B2/G1/G2/M1/C1/C2/P1分别选4/4/1/1/4/2/1/1个位姿对，每对两种光照整体选入。成员按固定字符串种子确定性选取，没有按评估结果调整。

这是一条序列、一个seed的初筛，不是三seed候选家族。没有用重复预测扩增独立样本，也没有放宽历史同预算R、历史A及三seed门禁。

## 诊断线索

材质组漏检由同类低置信度20→23、错类17→18、定位不足1→2构成；不是单一定位问题。材质组28个未匹配预测中，20个被预测为电容器组、7个开关柜、1个变压器。该分类是模型输出类别，尚未对这些新框做内容级视觉复核，不能把它们直接认定为某种建筑/柜体。

光照漏检则同类低置信度18→13、错类7→6、定位不足1→0，与召回改善一致。低阈值分类受NMS/max_det限制，不是原始网络全部候选的完整解释。

训练末轮box/cls/dfl损失为0.69664/0.63196/1.07827。训练成员末轮验证仅为训练拟合诊断，不是独立验证或候选选择依据。

## 开关柜训练覆盖账本：完成与待办

## 下一重要判断前应做什么

先暂停新训练配比，逐框审核本轮材质组的20个电容器类未匹配预测及3个新丢失计划目标，关联它们对应的设备/背景结构，核对全图标签和预测分配。与相同pair_id原始条件比较，判断退化集中于某些结构还是广泛降低置信度。不得把开发图或其派生图收入训练。

随后完成开关柜条件账本中与已发现漏检相对应的侧面/遮挡样本审核，再决定下一轮仅改变正样本组成，还是仅引入受控外观增强。若需要新实验，先冻结单一变化、预算和保留门禁，不同时改采样、增强、学习率和结构。当前证据不支持直接换大模型或追加采集数量。
