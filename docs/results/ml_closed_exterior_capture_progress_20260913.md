## 重放故障与责任范围

本轮新批处理工具把pair_id直接作为目录名，包含冒号。Gazebo把这些路径解析成URI，日志明确报告“Unable to find file with URI”和“Failed to find world”。16帧各3次技术尝试均在世界加载前失败，累计48份失败回执；没有生成有效掩码。此前成功的试点重放使用无冒号目录，因此不能拿它认证本轮新帧。

批处理也未在首个相同启动故障后终止其他帧，这是新工具的错误，不是数据或模型故障。所有失败回执及日志原样保留，旧回执确认本次启动进程已清理。训练没有启动，也没有将缺失掩码当作通过。

新增修复入口replay_closed_exterior_repaired.py：目录使用稳定哈希，不含冒号；启动前拒绝含冒号路径；整个批次在首个失败单元后停止；必须读取绑定本次预检身份的显式“新重试预算授权”才能重放。旧每帧3次已耗尽，不能通过新目录静默变成第4次。当前仅完成路径检查和针对性回归，尚未对修复版进行真实重放。
