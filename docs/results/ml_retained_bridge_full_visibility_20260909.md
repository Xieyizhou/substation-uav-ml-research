# 保留桥接数据全量实例可见性检测

## 最终判断

当前保留桥接数据的 13 个登记谱系、39 张图、159 个实例框已完成逐帧来源核验、精确重放与 AI辅助审核。8 个谱系（24 张）含内容不足实例，应在独立修订方案中整组暂缓；另 5 个谱系（15 张）通过本次全图可见性检查，但不自动取得训练准入。

现在已有足够证据设计独立修订方案，不需要先修复本机重放能力。仍没有新的通过检测的训练模型，本阶段没有训练。

全部 33 个内容不足框来自非计划目标：变压器 21 个、开关柜 12 个。去除三个同源变体的重复后，是 11 个“位姿—设备实例”组合；不能当作 33 个独立场景。计划目标电容器组、电抗器均有可辨识内容，但这不能替代对全图其他监督框的审核。

主要风险包括：前景遮挡后只剩顶部横条或侧边片段；左／下边界同时严重截断，只剩主体平面和基座片段；近景只剩顶板与顶部突出结构。没有设置可见面积阈值，像素数多不自动通过，贴边也不自动拒绝。

## 不能直接删图后续训

按照历史 I-300 的实际采样序列，若只将 8 个风险谱系整组移除、不重分配曝光，每个 seed 都会减少 153 次图像曝光，并减少以下监督：

| 类别 | 每 seed 减少的实例曝光 |
| --- | ---: |
| 变压器 | 216 |
| 开关柜 | 279 |
| 电容器组 | 45 |
| 电抗器 | 108 |
| 总计 | 648 |

这只是只读影响核算，没有实际删除成员或修改采样序列。即使问题框只有 33 个，整组处理也会影响同图中内容充足的目标，因此不能把旧训练结果和随意清理后的模型直接作因果比较。

另做了一个纯算术可行性核对：按上表五个谱系依次分配 20、39、18、19、24 次桥接图曝光，可在每 600 次总图曝光中的 120 个桥接槽位上，保持原先四类实例曝光总量 144／195／42／78。这不是训练协议：它不保持原有 13 谱系覆盖、实例身份、尺度分布或具体曝光位置，也不包含上一轮 8 个新位姿。先前关于“同时纳入全部新位姿并保持原约束”的不可行证明没有被推翻。

## 下一步方案建议

1. 冻结独立修订设计，暂缓 8 个风险谱系；不改历史标签，不单独删掉仍可见目标的框。
2. 以 5 个已核验谱系作为可研究的来源，先联合核算图像曝光、四类实例曝光、640 下实例尺度和谱系覆盖。上述算术解仅证明总数可匹配，不能替代这些约束。
3. 若需要补采，优先弥补整组处理损失的开关柜、变压器共现监督：避免近景设备只剩顶板，避开前景遮挡，逐图检查所有实例；同时保持电容器组、电抗器覆盖。不要只增加材质变体数量。
4. 数据与训练协议分别冻结后，再做同预算、同初始化、全 seed 的修订对照；仍用原开发门禁判断能力保留，不提前解封新场景。

## 解释与验收边界

标签保留完整不等于可见内容充分；full_2d 框包含遮挡范围也不自动构成标签损坏。当前证据支持存在监督内容风险，但不能证明它是材质敏感的唯一根因，也不能保证修订后模型改善。可辨识实体内容不等于类别独有几何特征充分；组件级主体／面板／基座证据仍记 unknown。
