# 配对视觉因素开发诊断（2026-09-07）

## 结论

`paired-visual-factors-v1` 已形成 12 个固定合法位姿、48 张完整配对图。四组均通过 `full_2d + visual-instance + top-level-equipment` 采集门禁和逐帧 AI 辅助审核；四变体目标框坐标差异为 0 px。结果支持“设备外观材质变化是本场景中最强的整体扰动因素”，但不能据此断言颜色是唯一根因，也不能外推到其他站点。

三份 66 张 uniform 开发参考权重在原始组的计划实例命中率为 0.917、0.833、0.750；材质组均降至 0.167，平均变化 -0.667。背景组平均为 0.556，较原始均值变化 -0.278；光照组平均为 0.472，变化 -0.361。uniform seed 间计划实例命中率标准差分别为：原始 0.083、材质 0、背景 0.096、光照 0.048。

冻结 v2.11 在原始组命中率仅 0.250，材质组为 0，背景组为 0.167，光照组仍为 0.250。它在本批上的低基线意味着其因素差值只能作为方向性证据，不能和 uniform 权重的绝对水平混为一谈。

## 边界与下一步

本批没有无目标图，因此不报告无目标帧误检率。每类仅三个位姿，结果只用于 complex 场景方向性诊断。背景组同时改变天空、地面和网格，无法拆分三者贡献。未调阈值，未训练，未读取保护标签，未晋升模型；全部新产物保持 `training_admitted=false`、`promotable=false`。

下一步补采优先级：先扩充 capacitor_bank 的材质与光照正交位姿；再给 reactor/transformer 增加相同距离分层和方位覆盖；为背景因素增加“仅天空”和“仅地面/网格”两个诊断组；另建无目标配对组评估误检。补采仍应按实例身份冻结，不根据模型成绩换图。

完整逐预测、逐匹配、逐 pair 差值和逐类明细见 `data/research/ml_training_recovery_v1/paired-visual-factors-v1/evaluation.json`；逐图审核及证据见同目录的 `semantic-review.json` 和 `review-evidence/`。
