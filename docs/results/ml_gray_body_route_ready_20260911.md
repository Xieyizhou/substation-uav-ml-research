# 可执行的下一训练途径：同源主体材质替换

## 结论及证据

推荐一次有界、固定预算的主体材质条件迁移对照，而非再提高同一批图的曝光量。

12 个位姿的完整诊断显示：高曝光 VM 三 seed 原始计划命中均为12/12，灰色主体下降到8/12、8/12、7/12，主要薄弱项为开关柜和电容器。面板新增损失只在G02出现，不能确认为跨位姿主要原因。主体条件替换因而是有证据支持的优先试验，不代表已确定唯一根因或保证改善。

## 数据与序列

新增12张灰色主体图均来自已核验位姿，逐标签AI辅助观察已记录；完整标签无损导出。对336张参考图及146034条登记指纹的精确文件／像素排除无重合，不读取保护标签。共享布局、资产与派生关系明确保留，不将变体当作独立场景。

以低曝光 VM 的seed7/17/27作为直接参考，每seed只替换原暖／冷变体的30个位置，其余2670个位置不变。完整类别实例曝光、负例位置与亮度系数保持一致。S07占8次，其余11个位姿各2次。减少暖／冷条件多样性是此策略的代价，不能解释成单纯增加灰色样本。

六个真实加载器（参考R和新组G，各三seed）共完成16200次实际加载，核验450批×6张、完整监督、位置成员及增强张量身份；参考增强日志与历史一致。预检禁止优化器、反向传播、训练和训练验证。最终机器就绪状态以 route-ready.json 的有效回执为准。
