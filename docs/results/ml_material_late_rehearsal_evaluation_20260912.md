# 后段材质曝光安排：三seed开发评估

## 最终判断

L-7/17/27均完成450步和固定48张配对图、48张无目标图的正式/低阈值评估。逐框AI辅助审核完成。没有通过完整门禁，不选择候选，不晋升。

本次来源级后段曝光安排未提高材质计划命中均值，seed间波动加大，且损失部分光照和电抗器能力。不能把“来源末次曝光更均匀”当作模型能力提高；也不能据此否定此前观察到的命中后丢失现象。

## 对照及结果

历史T为直接对照。每seed同2700次曝光、相同成员多重集，仅在原30个材质槽位中改变12个位置；所有非材质位置、负例和原位置亮度系数不变。部分批次组成及成员-亮度组合改变，实验识别的是时点安排策略整体效果，而非纯粹增加复习次数。

原始电抗器全图召回由80/100/60变为60/40/100；光照电抗器由40/40/40变为20/0/20。总体原始召回改善不能代替逐类能力保留。FPR各seed为6.25%、4.17%、10.42%，均值和最差seed仍通过既定FPR门槛，但相对T并未改善。

## 门禁及逐实例审核

未通过材质均值50%、材质最差seed1/3、光照均值60%的计划命中门槛；原始及光照电抗器相对retained_reference分别下降13.33、20.00个百分点，超过5个百分点容差。相对历史A还有电抗器及光照全图/变压器/开关柜能力保留失败。全部检查明细保存在evaluation/summary.json，不新增事后阈值。计划命中与一对一分配冲突为0。

720条逐实例跨seed比较中，持续命中332、持续漏检286、得益55、损失47。47个损失事件对应38个条件内唯一真值目标；事件不是独立场景。操作性原因：同类低置信度39、错类5、定位不足1、未发现合格保留预测2。最后一类受NMS/max_det约束，不能解释为网络从未生成候选。

本轮重新查看45张证据卡，记录10个无目标预测框（7张唯一图像、7个位姿）及38个新增漏检目标，共48条显式AI辅助决定，绑定图像、预测、完整真值、实例身份和证据哈希。误检包含灰色立面/面板、青色面板、截断立面及杆体混合结构，不按整帧主题推断资产身份。

新增漏检多有遮挡/截断，但也包含可辨的灰色变压器主体（E36）和面板主体（E41）。无可靠掩码，不认证像素级可见性；没有删除难例或改变全量指标。所有得益和持续状态保留。审核无未填写决定不等于重新认证全池训练质量。

## 下一优先方向

先用现有L与T权重，核对同一批实际曝光材质成员的拟合与此前13个命中后丢失事件是否恢复，区分“训练侧恢复但开发不延续”和“训练侧仍未稳定”。这只需要既有权重推理，不应立刻追加另一个时间排列、延长训练或换结构。

本报告未执行该补充诊断，因此不能宣布本轮已经解决或加剧具体成员遗忘的机制。当前开发结果只说明这一固定策略没有形成合格改善。保持training_admitted=false、promotable=false，不读取保护标签、不解封新场景、不自动开启下一训练。
