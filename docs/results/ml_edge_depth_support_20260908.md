## 核验结论

三个原始深度文件哈希与采集回执一致，RGB/深度时间差均为 0。保存的相机配置同安装点、同视场，RGB 1920×1080，深度 640×360。使用像素中心射线与保存世界中的静态视觉包围盒相交，分别报告轴向深度与距离两种假设，不把深度当作实例掩码。

| 审核 ID | 基座潜在深度采样点 | 主体潜在采样点 | 面板采样点 | 基座轴向深度残差≤2厘米 |
|---|---:|---:|---:|---:|
| T049 | 148 | 42 | 0 | 119 |
| T054 | 66 | 0 | 0 | 60 |
| T148 | 108 | 0 | 0 | 102 |

T049 主体有 28/42 个采样点轴向残差≤2厘米。基座残差中位数约 0.000017–0.000046 米；距离假设约 1.96–3.13 米。结果支持轴向深度下存在少量对应表面，不支持把框直接认作纯背景。但距离阈值仅为诊断统计，不是收录门槛。

结合前次原图 AI 辅助审核、实例映射与独立投影：更可信的问题是 full_2d 极端截断框内的类别可辨识内容不足，而非导出串图。T054/T148 主体和面板均在画外，只剩基座；T049 剩少量主体边缘。三者全部维持 hold_no_relabel、visibility=unknown。

深度不携带实例 ID，低分辨率及重合表面限制仍在；没有做渲染器实例掩码重放，不能宣称逐像素可见性认证，也不能据三个边缘案例解释全部训练退化。

## 统一处理规则草案（尚未应用到数据版本）

1. 对所有全图标签统一核验，不仅检查计划目标；设备主体、面板、基座分别记录可见证据、截断和遮挡。
2. 主体不可辨识、仅基座或附件可见、实例归属不确定的框进入待定，不因几何框存在就通过，也不自动删除该框。
3. 当前训练链路没有经验证的忽略区域语义。待定项应暂缓所在图像；同源配对作为整体暂缓，保留原始文件和缺口。不得将含其他目标的图改为空标签。
4. 不凭这三个案例制定可见面积百分比阈值。先按冻结规则扩展审核到同类极端截断与遮挡项，并保存逐框理由和证据身份，再冻结独立派生版本。
5. 若需要像素级结论，下一步以保存世界、实际位姿和相机参数开展独立实例掩码重放，先验证重放 RGB/几何与原帧一致。重放不覆盖原始证据，无法对齐则保持待定。
6. 数据版本修订后，才设计同初始化、同曝光预算、同 seed 的质量控制对照；本次不启动训练，不把清理效果预设为已证实。
