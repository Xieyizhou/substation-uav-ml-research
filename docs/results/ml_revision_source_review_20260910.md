# 来源闭包与风险目标复核

## 结论

四个已知训练成员完成原始 RGB 全像素一致性、完整标签坐标对应、保存世界哈希与唯一实例映射核对。T036 的来源登记可解析到原 pose；池内成员级谱系占位并非设备身份冲突。限定读取的四份来源账本中，该 pose 有一个成员，T027 的桥接 pose 有三个成员。该范围不是全局来源闭包或独立场景认证。

T027 的 original、neutral_bridge、background_bridge 三个成员均保存五个标签，均没有实例 128。逐图全景及底边放大图都可见极窄片段。neutral 的同帧实例证据已在此前诊断建立；另外两帧本轮没有重放，不能复制其掩码或直接认证归属。三帧均暂缓。

T036 的 11 个标签与来源对应；风险实例 118 的框主要被前景变压器覆盖，仅余窄顶部、侧面与底部内容，监督适用性仍待定。该帧继续暂缓。

## 审核范围和勘误

本轮明确查看四张全图叠框及四个风险局部，新增四条 AI 辅助审核决定。没有批准其余标签，也没有声称逐框全量质量验收完成。既有“计划目标可见／未截断”的审核不能延伸为非计划实例 128 或 118 已获批准；历史决定不覆写。

首次来源解析因历史 annotation_id 的零填充实例编号（如 0118）被严格拒绝；新工具改为规范化整数标签后再与世界映射对应，未降级成类别检查。原标签和历史脚本均未改动。

## 下一判断点

现有证据支持“标注生成缺陷与极端截断／遮挡监督风险同时存在”，不支持把模型退化归为唯一原因。先对 T027 的 original/background 两帧单独建立对齐实例证据，再形成整帧风险处理建议。即使恢复缺框，内容不足仍不能自动进入修订训练池。
