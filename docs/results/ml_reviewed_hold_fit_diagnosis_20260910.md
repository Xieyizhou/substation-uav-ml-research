# 已审核暂缓补偿模型：训练拟合与开发退化核对

2026-09-10。状态：诊断完成；不训练、不补采、不修改标签或阈值、不解封新场景。全部新产物 `training_admitted=false`、`promotable=false`。

## 核心判断

**本轮电抗器退化没有体现在已核对的训练成员召回上，主要证据指向训练条件之外的能力保持／条件迁移受限。** 这支持优先检验条件和视角覆盖，不支持直接把“优化步数不足”作为下一轮优先假设。不能据此认定唯一机制，也不能声称跨站点泛化失败。

三 seed 的两组模型，在共同已曝光的全部27个电抗器训练标签上均为27/27；其中此前独立审核为主体清楚的13个均命中，置信度也远高于0.37。与此同时，原始开发电抗器召回相对直接对照在每个seed都下降20个百分点。这不是“模型在所有画面都不会识别电抗器”，而是已有拟合没有稳定延续到开发位姿／条件。

## 身份、范围与方法

独立目录：`data/research/ml_training_recovery_v1/reviewed-hold-fit-diagnosis-v1`。

- 六份已训练终点权重：直接 LR=0.0005 对照和已审核暂缓补偿组，各 seed 7/17/27；权重、训练配置、2700次实际曝光及开发评估身份核验。
- 对冻结236张池成员各执行正式0.37与诊断0.001推理，共2832次图像推理。CPU、640、类别相关 NMS IoU=0.7、max_det=300、同类一对一 IoU≥0.5；使用全部标签，不只计划目标。没有采用MPS，避免设备变化干扰诊断。
- 每份权重记录自己实际曝光次数。六份权重共同曝光194张；主比较限于这一集合。共同曝光不等于曝光次数相同，不能把它当作新的单变量因果实验。
- 主体清楚集合沿用新推理前已有、图像及完整标签哈希有效的逐框审核：共同集合内13个电抗器、12个电容器组。没有按当前预测成绩重选清晰样本，没有把既有审核重新描述为本轮新审核。
- 每份输出保留全图预测、低阈值预测、完整真值、匹配和四类漏检，零曝光成员单列，不计为自身训练拟合成绩。训练成员结果只是拟合诊断，不是验收或泛化成绩。
- 推理进程封锁优化器创建、反向传播、YOLO.train及YOLO.val。六单元均首次推理完成，未改动历史脚本行为。

## 与开发结果联合解释

沿用有效CPU开发评估，不重新挑图或调阈值：

- 原始电抗器召回：对照80%/100%/100%，新组60%/80%/80%，三个seed均下降20个百分点。
- 光照电抗器：对照60%/60%/40%，新组40%/40%/40%。
- 材质全图召回均值从27.78%降到20.56%，三个seed均下降；材质计划命中均值从38.89%降到30.56%。

已证实：训练侧清晰电抗器高置信命中和定位保持，开发条件仍下降；少数桥接位姿训练拟合高，并不带来开发材质鲁棒性。

支持性解释：当前成员与条件覆盖狭窄、同源集中和成员—增强组合变化可能限制迁移；这些不是新发现的唯一根因。开发中存在清晰主体漏检，因此也不能全部归于截断遮挡。

尚未验证：是哪些视角、光照参数、材质反射或资产几何差异主导；训练侧与开发侧不是同一实例同一图像，不能把标签行身份用于跨图配对；也没有新场景盲测。重复seed预测不增加独立样本数。

## 下一优先方向

**优先设计来源隔离的条件／视角覆盖对照，而不是继续对现有4个位姿增曝或直接延长训练。** 先用现有来源世界和登记位姿建立覆盖矩阵，特别关注电抗器侧面、图缘、尺度、遮挡和原始／暗光条件，并区分材质、光照与几何。由矩阵确定一个单因素对照；若现有来源无法覆盖，才提出有界补采方案，不在本阶段采集。

后续若使用MPS，应将同轮参考和新组放在同一冻结后端并先做设备桥接，不拿MPS新组直接与CPU历史组作无混杂比较。本阶段仅输出诊断，不执行后续模型、增强、采样或采集变更。
