# Project Provenance

This repository is a clean research snapshot derived from the stable
[Xieyizhou/uav-path-planning-demo](https://github.com/Xieyizhou/uav-path-planning-demo)
PX4/Gazebo autonomy project.

The local source snapshot was prepared from commit `e4f99d6` on the
`research/ml-perception-platform` branch. The new repository intentionally
starts with independent Git history so its experimental milestones, datasets,
and validation claims remain separate from the resume-oriented demo.

The predecessor's MIT license is retained.

The September 2026 research preview retains that history and license. External
dependencies, dataset references and simulator assets are documented separately
in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). They are not relicensed by
the project MIT notice.
